# 渐升（ramp）实验的规划与预测——protocol-ramp

> **级别：主路径** ｜ 什么时候读我：要排渐升阶梯、算每档需多少 CFU 与累计乘客 ｜ 不用读我：只做单步 `optimize`
> 入口与完整分级见 `INDEX.md`。

> 适用：mutator 育种 / 耐受渐升筛选（多靶点、膜活性药、机制未知的药）。
> 本文档回答四个问题：**文献里渐升实验怎么做**、**哪些结果可以被预测（边界在哪）**、
> **`ramp` 规划器的数学**、**每档要记录什么**。
> 标注体系：[文献]（有出处）/ [推导]（本文档从文献推出）/ [约定]（本项目口径）。
> 姊妹文档：`protocol-fstep.md`（f_step 的铺板测量细节）；`multitarget-model.md`（窗口数学）。

## 0. 一页速览（决策流）

```
窗口结束的群体
   │
   ├─ 涂 3–4 个浓度的板（其中一块 = 下一步的工作板）→ 得到/更新 PAP 曲线
   │      f(c) = f_ref × 10^(−(c−c_ref)/δ)          [推导，δ 实测]
   │
   ├─ ramp --pap ... → 输出：可行最大步长 Δ、推荐梯级、
   │      每档预测 f_step ±CI、需铺 CFU、累计乘客、失守概率
   │
   ├─ 档间：群体传代（不挑单克隆）[文献，五篇协议]
   │      ├ 液传代（默认，2026-11-15 起）→ 存活者长到 N₀ 再开窗
   │      └ 板传代（备用）→ 整板刮取合并；两条路的取舍见 protocol-execution.md
   │
   └─ 每档实测 f_step 回填重算 —— 预测偏出 CI → 曲线重拟合
```

**j=1（单步可达）时不需要渐升**——直接 `optimize` 单窗直达；j≥2 才进本规程。j 的算法与实例见 `references/multitarget-intake.md` §-1。

**一句话定位**：`ramp` 不预测"耐药会怎么演化"（那是进化学派的研究问题，
且 pcbi.1014666 已证明简单模型只能"部分"预测）；它预测**下一档的供给、
板量与累计代价**——这两件事文献里要么没人做，要么做得比我们粗。

## 1. 文献里的渐升实验怎么做

### 1.1 进化实验学派（experimental evolution）——群体传代

五篇协议原文（本地均有全文）的转接规则汇总：

| 研究 | 药/体系 | 升浓度规则 | 档间操作 | 单克隆何时挑 |
|---|---|---|---|---|
| PLoS Genet 2025, `10.1371/journal.pgen.1011627` | 5 药 × E. coli 13 株（含 mutator） | **同板 12 梯度孔**，自适应爬孔 | 24h 后从"OD>0.03 的最高浓度孔"**整体收集**转接新梯度板；9 天 ≈70 代 | 终点 |
| AAC 2026, `10.1128/aac.01414-25` | 达托霉素/万古霉素，S. capitis | 5 档起始；"**cultures from the highest antibiotic concentration that still permitted growth were used for the following day**"；耐药后最高浓度加倍 | 每 24h 只测 MIC（E-test） | 终点 WGS |
| Nat Commun 2026, `10.1038/s41467-026-74044-6` | 8 药，mutator 群体大小实验 | 1:50 串代 28 天，升到 ~1000×MIC | 群体 1:50 传代 | **终点**："A single colony was isolated from each population" |
| Science 2017, `10.1126/science.aaj2191` | 氨苄间歇暴露，E. coli | 每日间歇暴露，群体批培养 | 每日转接 | **终点**：分离首个确立的耐药克隆 |
| Nat Genet 2012, `10.1038/ng.1034`（morbidostat） | CHL/DOX/TMP | 装置动态维持"抑制边缘"（Δt=11 min，OD 阈值 0.15） | 连续培养，无离散档 | 终点（47 SNP 图谱） |

**共同点（写进协议的规则）** [文献]：

1. **群体传代**——从"仍允许生长的最高浓度"整体取样转接，**档间不挑单克隆**；
2. **自适应升档**——长起来才升，没长原地重复（morbidostat 把这条做成了闭环控制）；
3. **单克隆只在终点**分离（MIC 确认 / 谱系分析 / WGS / 保藏）；
4. 每档都测表型（MIC 或存活曲线）——**升档判据来自测量，不来自日历**。

**为什么档间挑单克隆有害** [推导]：每挑一个就是一次单谱系瓶颈——4 步 ramp 后
所有"独立克隆"共享同一谱系，mutator 产生的多样性红利清零；且 f_step 的定义
（群体频率）依赖群体传代才自洽。

**一处曾经偏离、已收回** [约定]：文献的转接判据全是**液体 OD**。本规程早期版本
为了避免"异质性生长使 OD 不可靠"（见 §2.2 第 3 条），改成**板上传代 + 克隆计数**——
但板传代把群体压成"板上的 C 个克隆"（每档一次单谱系瓶颈），且板内 20–27 代
是结构下限（`log₂(每克隆细胞数) × M_off`）。2026-11-15 起推荐**液传代**：
判读不靠 OD，而靠"48 h CFU 增长倍数"，既回到文献的群体传代主流，又避开 OD 的坑。
**取舍、桥接验证（f_liq vs f_plate）与操作卡见 `protocol-execution.md`。**

### 1.2 药企多步筛选学派——琼脂板倍增浓度

化合物耐药表征的传统做法：琼脂板倍增浓度串代，**从最高浓度板收生长菌**
（一群，不是单克隆）接下档；配套"单步频率"实验（大接种量 + 单一高浓度板）。
与进化学派的差异：目的是给化合物做耐药表征，不控制代数、不算代价。
**我们的板式 f_step 在操作上更接近这一派，在目的上属于前一派**——两个都要引。

### 1.3 装置与自动化（要不要上 morbidostat？）

morbidostat（`10.1038/ng.1034`；低成本的见 JoVE `10.3791/54426`）用闭环控制把
培养物**持续**压在抑制边缘——它的"浓度"是连续变量，没有"档"。GitHub 上有多个
开源实现（neherlab/python_morbidostat 等）与 eVOLVER 连续培养平台。
**对我们的含义** [推导]：装置方案省人力但 (a) 不产出离散克隆（产物是群体），
(b) 乘客无法按窗记账，(c) 诱导时序（我们的 mutator 开关）难以叠加。
育种目的下，板式离散档是更可控的形态——装置适合做**探索性**的可行性预实验。

## 2. 预测的文献边界：birth-death-mutation 模型 predict some—not all

`10.1371/journal.pcbi.1014666`（PLoS Comp Biol 2025，生物反应器 × 3 药 × 定量
复测）是我们预测器的**适用范围声明**，精读结论四条：

### 2.1 简单模型的四种失败模式 [文献]

| 失败模式 | 哪个药暴露的 | 对我们的含义 |
|---|---|---|
| **表型延迟**（突变后蛋白重构未完成，短暂仍表型敏感） | RIF——加入延迟后模型恢复预测力（再生概率 50%→9%，指数期） | 膜药的滞后比 RIF 严重得多（脂质组重构以小时计）——**f_step 会截断晚期突变** |
| **等位基因效应异质**（不同耐药突变长速不同） | RIF——需按等位基因分别给生长率 | 乘客账不受影响（见 §3.4），但"每档克隆数"有谱系竞争 |
| **丝状化**（敏感细胞拉长不死，占据空间） | CIP | 板上表现为"长得慢的小菌落"——坑 10 的 time-to-visibility 记录 |
| **波动实验 μ ≠ 实际条件 μ** | CIP/STR——**低估 2–7×**（CIP: 1.2→2.8×10⁻⁹；STR: 0.69→4.7×10⁻⁹）；RIF 恰好一致（6.2 vs 8.3×10⁻⁹） | **f_step 必须在实际选择条件下实测，不能从波动 μ 外推**——这是 f_step 教义的文献实锤 |

### 2.2 三条直接含义 [推导]

1. **供给实测主义有了定量依据**：同一个标记（rpoB）在波动实验与反应器里给出
   差 2–7 倍的 μ，取决于生长历史。任何"从 μ 算供给"的路线都继承这个偏差——
   这就是 11-13 删除 μ×T_set 路线的文献确认。
2. **预测器必须带"可测-预测-审计"闭环**：pcbi.1014666 的作者用"模型拟合实测
   分布反推真 μ"来修正——对应我们的"每档 f_step 回填重算"。预测器不审计 = 没有预测。
3. **失败是药物特异的**：RIF 能预测不等于 CIP 能预测。换药 = 换一条 PAP 曲线 +
   重新验证平稳补充假设，没有免费的迁移。

### 2.3 他们也确认了我们的边界 [文献]

pcbi.1014666 的"some—but not all"边界与我们画的一致：
**可预测**：群体水平的再生概率、耐受/耐药克隆的**数量分布**、达到阈值浓度的时间尺度；
**不可预测**：哪个突变、哪条路径、CNV 何时发生（另见 Nat Microbiol 2026
`10.1038/s41564-026-02415-2`：基因扩增是适应第一大类，常规短读 WGS 都未必数得清）。

## 3. `ramp` 规划器的数学

### 3.1 PAP 尾部拟合 [推导，模型原型见 §2]

**输入**：同一窗口后群体在 m 个浓度上的铺板计数 (cⱼ, kⱼ, nⱼ)。
同浓度多板合并（k、n 分别求和）；k=0 的行不进拟合，按 rule of three 记检测上界
3/nⱼ（Hanley & Lippman-Hand 1983），拟合值高于上界时报警。

**模型**：log₁₀ f = a + s·c，最小二乘；**δ = −1/s**（十倍频浓度宽，单位与 c 相同）。
约束 s < 0（浓度升高频率下降）；R² 报告拟合质量；正克隆点 <3 时 δ 无 CI
（预测只有点值，报告显式注明）。

**预测**：f̂(c) = 10^(a + s·c)，95%CI 用回归预测区间
（±1.96·√(σ²·(1+(c−x̄)²/Sxx))）。**外推警告**：预测点超出最高实测浓度
超过 1 个 δ 时显式标注——远端档最脆弱。

### 3.2 平稳补充假设（planner 的核心假设）[推导，带实证边界]

**假设**：等步长 Δc 下，每个诱导窗口的突变供给把耐受尾部"重新填满"到
≈ 相同的频率——即每档 f_step ≈ 首档实测 f(c_start+Δ)。

**依据**：
- pgen.1011627 的加性模型（每次突变对 log-MIC 的抬升恒定 ε）+ 其串代实验
  中 MIC 指数爬升的实测轨迹；
- AAC 2026 / Nat Commun 2026 的实践：每档转接后频率"长回来"才能继续爬；
- 我们的 f_step 本来就是实测——假设错了会在下一档的测量里立刻暴露。

**失效场景**（出现即停用、重拟合）：机制天花板（Δc 超过单突变可跨越的范围，
pgen.1011627 的例外株 LQ 即此类）；谱系效应（pbio.3001878：mutator 走 WT
不常见的路径——可及路径集合本身改变）；CNV 涌现（Nat Microbiol 2026
`10.1038/s41564-026-02415-2`——扩增高频但不稳定，会同时扰动 f_step 与乘客账）。

### 3.3 可行步长与梯级 [推导]

**可行条件**（每档）：预测 f_step × 板容量 ≥ k × margin。
从 f(c_start+Δ) = k·margin/capacity 解出**可行最大步长**：

```
Δ_max = δ · log10( f(c_start) · capacity / (k · margin) )        [推导]
```

（由 log-线性模型直接解出；margin 默认 3.0 [约定]——留出挑克隆验证的余量。）

**梯级**：均匀步长 Δ = span/S，S = ⌈span/Δ_max⌉，span = c_target − c_start。
步长均匀的理由：每档可行条件相同（平稳补充），均匀划分使每档的频率余量相等。

**卡住（stuck）**：f(c_start)·capacity < k（起步即不可行）或 < k×margin
（margin 下不可行）→ 输出富集/加容量/降 k 三条建议，**不出梯级**。

### 3.4 乘客四段账（跨窗可加）[推导]

无性谱系里突变不可逆，最终基因组的乘客 = 全路径突变之和（期望线性可加）：

```
E[P_总] = Σᵢ (n_win,i × M_on)              ← 窗口段（诱导开着）
        + Σᵢ (n_plate,i × M_off)            ← 档间扩增段（板/液，诱导已关）
        + Σᵢ tail_i                          ← 洗脱尾（每次洗脱计一次）★
        + n_post × M_off + tail              ← 终点后段
```

**洗脱尾 `tail`** [推导]：洗脱时效应蛋白/突变酶不是瞬间消失，而是按 τ_off 衰减，
档间扩增的前几代仍带着 > M_off 的活性。按"每代 td 小时"离散求和：

```
tail = (M_on − M_off) · Σ_{g≥1} exp(−g·td/τ_off)
     = (M_on − M_off) / (exp(td/τ_off) − 1)
```

连续极限（td ≪ τ）退化为 `(M_on−M_off)·τ/td`，与 `fit-tauoff` 报的尾部负荷同口径。
`multitarget` 里由 `--tau-off-h` + `--td` **同时给出**时计入；只给一个会直接报错，
都不给则在报告里明写"未计入"（尾项可与板内段同量级，漏掉就是低估）。

- 驱动与乘客是独立泊松流（同一聚合酶错误、不同靶标），条件化在
  "每档拿到驱动"上不改变乘客分布——三段可以干净相加；
- 修正项 ①：幸存者偏差（有害乘客多的谱系长得慢）→ 实际略低于账面（保守上界）；
- 修正项 ②：菌落不是克隆——板内扩张晚期的亚克隆突变不进共识基因组；
- M 的参数不确定性是**全窗共享**的（2–10×，见 multitarget-model.md §8.4），
  不能当独立误差相加。

**板内扩张为什么常常是大头** [推导，符号]：板内段 = n_plate × M_off。
只要 `n_plate`（菌落 1 个细胞 → 可见菌落，通常 20–27 代）与 `n_win`（窗口代数）同量级，
板内段就与窗口段（n_win × M_on）可比——**M_on/M_off 的比值越大，板内段相对越小**。
把自己体系的 M_on、M_off、n_win、n_plate 代进去就能判：这是本规划器 `--n-plate` 那一项的意义。
（数值示例请用你自己的菌株卡跑 `multitarget`，本文不给通用数字。）

### 3.5 失守概率：总乘客单次代入 [推导]

```
P_失守 = 1 − Πᵢ exp(−Pᵢ × ℓ) = 1 − exp(−E[P_总] × ℓ)，   ℓ = L_prot/G
```

概率不能按档相加（重复计入双命中）；单命中主导段（P_失守 ≲ 5%）里
"朴素相加"与严格式数值接近（4 步示例 4.04% vs 4.0%），但档数增多或 λ 变大
时偏差显形——**实现与文档一律用总乘客单次代入**。

**比可加性更重要**：失守克隆不会被淘汰（丢掉产素负担甚至可能长得更快），
群体会随代数富集失守谱系——**每档抽检保护区完整性**（跨簇菌落 PCR / 产物
检定）是唯一能把这项从账面数字变成受控量的办法。若自保护基因在簇内
（如 microbisporicin 的 MibEF，`10.1073/pnas.1008285107`），失守克隆还会被
周边产素者的背景浓度反杀——净效应方向需一次混培实验核实。

### 3.6 按需诱导门控 [推导，本会话]

供给富余（f·capacity/k ≫ margin）的档**可以关诱导**：省掉
(M_on − M_off) × n_win 的乘客。但有两个前提：泄漏先修到红线内
（否则"关"也要付泄漏倍数 M_off/M_base 的地板价）；且关诱导会降低
后续档的 f_step（供给变少）——门控决策要用未诱导对照臂的实测 f_step 支撑
（P2 设计已有该臂）。

## 4. 与文献做法的对照表（偏离与理由）

| 维度 | 文献主流 | 我们 | 理由 |
|---|---|---|---|
| 传代介质 | 液体（OD 判读） | **板式**（克隆/CFU 判读） | 膜药异质性生长使 OD 不可分辨（eLife 2024 低积累者；Science 2017 慢长谱系误判）[约定] |
| 升档判据 | OD 达阈值即升 | f_step 实测 + CI | 同上；且窗口优化需要频率而非存活 [约定] |
| 档间挑克隆 | 不挑（群体传代） | 不挑（同文献） | 一致 [文献] |
| 单克隆分离 | 终点 | 终点 + 中途抽检（PAP 复测/完整性 PCR） | 我们额外有 BGC 保护约束 [约定] |
| 诱导时序 | 无（组成型系统） | 窗口内开、窗口外关 | mutator 特有；泄漏核算是我们的新增项 |
| 乘客核算 | 不做 | 三段账 + 失守概率 | 育种目标特有 [约定] |

## 7. 与 `multitarget` 命令的对应

`fstep`/`ramp` 两个子命令已并入 `multitarget`（账本解释器，2026-11-14）——
**records 账本是唯一状态文件**，命令读取全部历史记录，输出四段：各档 f_step →
PAP 现状（平稳性审计）→ 下一窗设计 → 剩余梯级与累计账。

```
python3 run.py multitarget --records records.csv --markers markers.csv \
    --genome-mb <Mb> --n-win <窗口代数> --n-plate <板内代数> --m-off <泄漏 M_off> \
    --n-post <终点后代数> --k <目标克隆数> --capacity <板预算> --c-target <目标浓度> \
    --bgc-kb <要保护的 kb> \
    --tau-off-h <τ_off h> --td <倍增 h>          # 同时给才计洗脱尾
    # 可选：--sat-f <饱和阈值，默认 0.5>       # f_post ≥ 该值不进尾部拟合
    # 可选：--propagation {manual,plate,liquid}  # 档间代数由拓扑自己算：
    #        plate 要 --cells-per-colony；liquid 要 --nt（--n0 可覆盖）
```

- `--records`：§5 的记录字段表（cycle, c, when=pre/post, cfu, clones）；
  每档多涂的浓度板就是 §3.1 的 PAP 点——零克隆行自动作上界；
- `--n-win`：§3.4 的 n_win（P0 实测 td 与 Nt_sat 钉死后填有效代数）；
- `--n-plate`：§3.4 的板内扩张代数（= log₂(克隆细胞数)，实测填入）；
- `--m-off`：§3.4 的 M_off（不给则窗口外段不计入并注明）；
- `--margin`：§3.3 的可行性安全倍数（默认 3.0）；
- 每档执行完把新记录**追加**进 records.csv 重跑——上一份报告的预测与本档实测
  的对照就是平稳补充假设的审计（偏出 CI → 曲线重拟合/拆档）。

旧 `fstep` / `ramp --pap` 的单档口径分别由输出①与②④覆盖，功能无丢失。
