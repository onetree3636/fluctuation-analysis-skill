## 0. 三条旧做法都是错的（先破）

| 旧做法 | 为什么错 |
|---|---|
| **按药类分**（脂肽 / 羊毛硫肽 / …） | 同一化学类里既有"单模块一步可及"也有"多模块协同"，按化学类分会把机制相反的药放进同一格 |
| **按"是否多靶点"分** | "多靶点"混了两件事：**多结合位点** vs **多致死机制**。存在"单结合位点 + 双致死机制"的药，也有"多结合位点"的药 |
| **按"靶点是蛋白还是脂质"分** | 脂质靶点同样可以高亲和、单点修饰；蛋白靶点同样可以多模块。结合对象的化学身份不决定抗性结构 |

**并且：`k·F` 作为加速倍数比是错的。**
并联靶点数 `k` 改变的是**绝对等待时间**（`1/(k·μ·N)`），但在 mutator vs WT 的**比值**里 `k` 约掉了：

```
等待时间(WT)   = 1/(k·μ·N)
等待时间(mut)  = 1/(k·F·μ·N)
比值 = F          ← 与 k 无关
```

所以加速比就是 **`F`**：`k` 只影响"多久"，不影响"快几倍"。
（`F^j` 是"谷型"情形的上界，**本实现不建模**——见 `multitarget.py` 模块头。）

## 1. 主判据：**抗性通路的模块结构**（决定 `j`，因而决定加速比）

不看药，看**耐药是怎么来的**。这是唯一真正决定 `F` 的边际作用的量。

| 类 | 定义 | `j`（顺序步数） | 加速比 | 典型抗性机制形态 |
|---|---|---|---|---|
| **S 类（单模块）** | 抗性可由**单个基因/单个操纵子**的获得性改变达成，且效应量大 | **1–2** | **≈ F**（至多 `F²`） | 靶点修饰、靶点遮蔽、靶点保护型转运、降解酶、单个调控子组成型激活 |
| **C 类（多模块）** | 达到目标耐药水平需 **≥3 个独立模块协同** | **3–6** | **加速 ≈ `F`**（时间是若干 1/μ 的和） | 膜脂质组成 + 外排 + 细胞壁 + 调控网络叠加 |
| **U 类（未定）** | 无抗性证据 | **未知** | **不给数** | — |

> **判 S 还是 C 的关键问句**：*你能筛到"一步到位"的耐药突变体吗？*
> 若能，且其 MIC 跃升 ≥ 目标水平的 1/4 以上 → S 类（`j` 小）。
> 若只能靠逐步递增浓度筛出来、且单步跃升很小 → C 类（`j` 大）。

## 2. 辅判据：**结合特异性**（只作先验与机制预测，**不设数字**）

这一维不决定 `j`，只决定"该去查哪些机制"。

| 结合类型 | 含义 | 抗性通常发生在 | 对 `j` 的先验 |
|---|---|---|---|
| **分子特异** | 依赖一个高亲和、身份明确的分子（某前体、某脂质头基、某蛋白） | **该分子的可及性**：修饰、遮蔽、隔离、转运保护、降解 | 偏小（1–2），但不保证 |
| **体相性质** | 作用于膜脂质组织、电荷、电位等整体属性 | **包膜整体重塑**（多基因） | 偏大（3–6），但不保证 |

⚠ **下面这张表只是「先验」，不是判据。**
**靶点清楚 ≠ S 类；靶点不清楚 ≠ C 类。**
定类只看一条：**你能不能一步筛到耐药克隆**（能 → S；只能一级级爬 → C；没做 → U）。
理由：有明确靶点的药也可能改不动靶点、只能靠外排+膜改造叠加（C 型）；
没有明确靶点的药也可能一个调控子突变就打开整套修饰基因（S 型）。

**两维交叉（只是先验，不是结论）**：

| | 抗性 = 单模块 | 抗性 = 多模块 |
|---|---|---|
| **结合 = 分子特异** | **S 类典型**：靶点被修饰/遮蔽/搬走即可；单调控子也能组成型打开整个修饰操纵子 | 过渡型：靶点特异但高水平需叠加包膜改变，`j` 落在 2–4 |
| **结合 = 体相性质** | 少见，但存在：单个主调控子可同时改写多个下游基因 | **C 类典型**：膜脂质 + 外排 + 细胞壁 + 调控协同 |

> **注意**："结合分子特异"**不等于**"抗性容易"。
> 若靶点被高效保护（转运体把药从靶点旁搬走），单模块抗性同样可以很强——这仍是 S 类。

## 3. 统一表述（写进技能的主句）

> `F` 是**突变供给倍数**，不是速率倍数。
> 抗性出现速度的加速 **≈ `F`**（线性）。`j`（顺序步数）只影响"多久"，不影响"快几倍"：
> - `j = 1`（单步即可）→ 加速 `F`；
> - `j ≥ 3` → **仍是 `F`**（各步等待时间相加；本实现只建这一档）；
> - `j` 未知 → 先做 D1/D2/D3 定 `j`，不要用 `F^j` 顶替。

---

## 4. 两条修正项（必须同时写）

**① `F` 不是纯标量：mutator 会"改道"**
突变谱改变 → **可及路径集合改变**。已有实证：MMR 缺陷株走出野生型少见的第一步
（含"外排组分失活反而增耐药"这类反直觉路径），把该突变回接到野生型仍给 4–6 倍耐药。
→ 模型必须允许"路径集合随 mutator 变化"，不能只调 `μ`。

**② 路径有"延迟承诺"**
早期路径不锁定、可逆。"首步定路径"应弱化为"首步**偏向**路径"。

## 5. 怎么定类：**靠证据，不靠猜药**

```
输入：药 + 是否已知靶点 + 单靶点 μ / F
│
├─ Q0 抗性是遗传的吗？（三态判定：表型持留 / 遗传耐受 / 耐药）
│   └─ 表型 → 终止（mutator 无效）
│
├─ Q1 有没有"一步到位"的耐药突变体？（单步筛选）
│   ├─ 有，且单步 MIC 跃升 ≥ 目标水平的 1/4 → **S 类**（j 记 1–2）
│   └─ 没有 / 只能逐级递升 → Q2
│
├─ Q2 独立克隆里，每个克隆累积了几个独立模块？
│   ├─ 每克隆 1 个模块，不同克隆命中不同模块 → **S 类**（并联入口，j 仍 1）
│   ├─ 每克隆 ≥3 个模块协同 → **C 类**（j 由步数计）
│   └─ 1–2 个模块 → 过渡型（j 取 2–3，标 uncertain）
│
└─ Q3 以上都没做 → **U 类**：只输出"F 可作供给倍数"的定性结论
        + 强制给出 Q1/Q2 的最小实验（见 §6）
```

**关键：允许"未定"。** 强行归类会产生虚假的定量结论，比不给数更糟。

## 6. U 类（新药、机制未知）的标准动作

这是最常见的情形，技能必须能直接回答"我什么都不知道时怎么办"。

**默认处置**：按 U 类报告，只给三句：
1. `F` 可以作为**突变供给倍数**使用（这是唯一无条件的结论）；
2. **不给** `j`、**不给**加速倍数的数；
3. 给出下面的定类实验（成本递增，可按资源裁剪）。

| 步骤 | 做什么 | 产出 | 大致周期 |
|---|---|---|---|
| **D1** | 单步筛选：高浓度平板直接铺，看能否一步拿到耐药克隆 | 有/无 → 分叉到 S 或 C | 3–5 天 |
| **D2** | 梯度传代：逐级递增浓度，记录每代 log₂MIC 增益 | 曲线形状（阶梯 vs 平滑）→ `j` 的量级 | 10–14 天 |
| **D3** | 全基因组测序 8–12 个独立耐药克隆 | 每克隆的模块数 → 定 S/C，并给出 `j` 的实测值 | +2–3 周 |

> **判读要点（D2）**：阶梯状（长时间平台 + 突然跃升）= 需稀有突变、`j` 大；
> 平滑上升 = 多步但每步易得。两者对 `F` 的响应不同。
