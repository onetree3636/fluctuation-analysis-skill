# 多靶点外推的数学模型

> ⚠ **2026-11-13 路线收缩**：`--mode design/fit/classify` 已删除（μ 外推供给属假精度）。多靶点只剩一条计算路径：`multitarget --f-step …`（供给实测）。本文讲的概念（分类轴/标度律/α）仍可用于**规划与解读**，但不再有对应的可执行模式。


> **这是进阶文档（有公式）。** 第一次接触请先读 `docs/multitarget-tutorial.md`；
> 只想快速判断该做什么，请看 `docs/start-here.md`。

> 配套命令：`multitarget --mode design|fit|classify`。
> 本文件只讲"公式是什么、什么时候成立、什么时候失效"。
> 分类轴（S/C/U）见 `multitarget-extrapolation.md`；证据从哪来见 `resistance-evidence-tiers.md`。

---

## 0. 三个量，别混

| 符号 | 含义 | 单位 | 怎么来 |
|---|---|---|---|
| `μ` | 单 locus 每代每细胞突变率 | /locus/代 | `rate`（波动实验） |
| `F` | 突变株相对野生型的 `μ` 倍率 | 无量纲 | `compare` 两批 |
| `N` | 有效群体（每管/每代瓶颈） | 个 | 平板计数 / 菌株卡 |

`F` 是**供给倍数**，不是速率倍数。所有下面的推导都只把 `F` 当"μ 乘了几倍"。

---

## 1. 供给：先判断"饱和没有"

```
每代产生的单步抗性突变数   S = N · μ
```

| `S` | 判定 | 后果 |
|---|---|---|
| `≫ 1`（≥10） | **饱和** | "有没有耐药克隆"失去分辨力，必须改测"多久" |
| `≈ 1` | 边缘 | 出现率指标分辨力差 |
| `< 1` | 正常 | 出现率可用，符合经典 L-D 前提 |

**为什么必须先算这一步**：经典波动分析假设突变稀有（`S ≪ 1`）。
`S ≫ 1` 时单步突变每代都发生很多次，克隆干扰（clonal interference）主导，
所有"等待时间"公式的前提都不成立。

---

## 2. 两种标度律（C 律已移除）

### A. 单步（`j = 1`）

```
T ≈ 1 / (2·N·μ·s)              s = 选择系数
加速比 = F
```

`s` 是三者里最难知道的量；不知道时取 0.1 并在输出里标明是假设值。

### B. 串联，但中间态**可被选择**

每一步的突变体都能长起来、固定后再等下一步。等待时间**相加**：

```
T_j = Σ_{i=1..j} 1/(2·N·μ_i·s_i) ≈ j · T_A
加速比 = F                    ← 线性！不是 F^j
```

**这是最常被误解的一点。** 即使要 5 步，mutator 的加速仍是 `F`，
因为时间是若干"`1/μ`"的**和**，不是乘积。

> **C 律（谷型，`T ∝ μ^-j`）已于 2026-11-12 移除**：本项目全部是升浓度协议（连续性状，
> 如 1 g/L → 5 g/L），中间态在结构上必然可被选择，谷型不会发生。保留它只会让人误以为
> 报告里的 `F^j` 需要认真对待。若将来真遇到谷型体系，公式是 `T_j = s^(j−2)/(2Nμ^j)`
> （Iwasa/Michor/Nowak 2004；Armitage & Doll 1954），按此重写即可。

---

## 3. 统一形式：`T ∝ F^(-α)`

```
log T = log A − α · log F
```

| `α` | 含义 | 场景 |
|---|---|---|
| `0 < α < 1` | 收益递减 | 克隆干扰主导（大群体、已适应背景） |
| `α = 1` | 线性 | 单步，或串联但中间态可选（**本实现只建这一档**） |

**本实现只建 `α = 1`**：加速 ≈ `F`。`α` 的实测值由 `--mode fit` 给出；若明显 >1，先查测量误差或路径结构。

---

## 4. 怎么测 `α`：斜率法

1. 取 3 档突变率（`F₁=1`、`F₂≈10`、`F₃=目标`），每档 ≥4 重复；
2. 每档跑梯度传代，记录**达到同一 MIC 级别**所需的代次 `T_L`；
3. 对 `(log F, log T_L)` 做线性回归，`α = −斜率`。

**为什么用 3 档**：2 档只能给点估计、CI 不可估（自由度 0）；3 档才有 1 个自由度，
但 CI 会很宽——这是诚实的，不要为"让 CI 好看"而删组。

### 可辨识性：什么时候这个实验**测不出来**

- 目标档的 `T_L` 短于半个世代 → 快到数不出来（`F` 太大或 `μ` 太大）；
- `T_L` 超过实验总代数 → 跑不到（`F` 太小或 `j` 太大）；
- 两档之间的差异小于噪声（`2·CV/√重复`）→ 分不开。

`multitarget --mode design` 会把这三条都算一遍，给出"可分辨的 α 区间"。

---

## 5. 一个算例（把数字走一遍）

`μ = 2×10⁻⁷`、`N = 10⁸`、`F = 50`、`j = 3`、`s = 0.1`（虚构示例）：

```
S = N·μ = 20 /代              → 饱和（≫1）
T_A = 1/(2·10⁸·2e-7·0.1)     = 0.25 代
T_B = 3 × 0.25               = 0.75 代
```

**读法**：
- 单步/串联都在 1 代内 → **看"多久"也测不出来**，因为快到没有分辨率；
- 所以对这个体系，**模型的绝对时间是失效的**：它只会告诉你"要么立刻、要么永不"。

这正是 `--mode design` 在饱和时输出"不给 α 的预测值"的原因。
此时唯一可行的是**直接测**：跑 3 档，实测 `T_L` 的经验值，再拟合斜率。

---

## 6. 三个必须声明的局限

1. **波动实验分不开 `k` 与 `μ`**：`k` 个独立位点等价于把 `μ` 乘以 `k`，
   得到的是乘积 `kμ`。要拿 `k` 只能靠全基因组测序（看不同克隆是否命中不同模块）。
2. **模型的绝对时间在 `S ≫ 1` 时不可信**：稀有突变 + 逐级固定的前提已破。
3. **`F` 不是标量**：突变谱改变会让可及路径集合改变（见 `multitarget-extrapolation.md` §4），
   此时"同一个 F"在不同药物上不等价。

## 8. 出处与可信度（2026-11-12 补）

此前本节不存在，代码与文档都没有引用——**公式是经典的，但出处没写，读者无法核**。补齐如下。

### 8.1 有文献支撑（可当预测用，注意适用域）

| 公式 | 出处 | 备注 |
|---|---|---|
| 建群概率 `≈2s` | **Haldane 1927**, *Proc Camb Phil Soc* 23:838–844 | 分支过程的标准结果；`2s` 只在 `s≪1` 时成立 |
| `T_A = 1/(2Nμs)` | 由上一条直接得（速率 = `Nμ·2s`） | 现代处理见 `10.1073/pnas.1119910109`（克隆干扰下 `2s` 被修正） |
| `T_B = Σ 1/(2Nμᵢsᵢ)` | 独立指数等待时间相加（Erlang/gamma 均值） | 前提：每步的突变体都能被选择并固定 |
| 饱和/克隆干扰（`S=Nμ`） | **Gerrish & Lenski 1998**；**Wilke 2004**, *Genetics* `10.1534/genetics.104.027136` | 后者的结论是"高 μ 下没有简单闭式解"，故本模块在 `S≫1` 时拒绝给绝对时间 |
| 耐受先于耐药 | **Levin-Reisman et al. 2019**, *Science* `10.1126/science.aaj2191` | 支持"中间态可被选择"（B 律）在真实体系里常见 |

### 8.2 无文献支撑（作者综合，只能当区间读）

| 内容 | 位置 | 处理 |
|---|---|---|
| `加速 = F^α`，`α ∈ [1, j]` | `accel` / `_regime_name` | 文献只给"线性 vs 隧道"二分；连续 α 是经验参数化 |
| `s = 0.1` 默认 | `design` | 输出已标"假设值"；`s` 应由实验定 |
| `rounds = 16`（≈106 代） | `design` | 经验值（12–20 轮），非最优解 |
| 饱和阈值 `1 / 10` | `saturation` | 量级判据，不是相变点 |
| `α` 区间阈值 `0.5 / 1.3` | `_regime_name` | 命名用，不参与计算 |
| `classify` 的 `1e-9 / 1/4 / 1.5 / 3` | `classify` | D1–D3 操作经验 |

### 8.4 位点→基因组换算的出处（target-size 法，2026-11-13 补）

`M = μ_marker × G / T_eff`（推导见 `docs/mu-genome-derivation.md`）不是本项目的发明，
是波动分析文献的标准做法。按证据强度列出：

| 环节 | 出处 | 说明了什么 |
|---|---|---|
| 方法传统 | **Drake et al. 1998**, *Genetics* 148:1667, "Rates of Spontaneous Mutation" | 把单位点/表型速率经有效靶标换算成每碱基速率的综述性处理；细菌"每基因组每代 ~3×10⁻³"的 Drake 常数即由此来 |
| 每标记 ÷T_eff 换算的原型（**T_eff 是实测的**） | **Lang & Murray 2008**, *Genetics* 178:67–82, `10.1534/genetics.107.071506`（PMC2206112 全文已读） | 3 个表型标记各自 MSS-MLE 测速、各自除以**由 207+227 个抗性克隆突变谱测得**的 T_eff（bootstrap CI）；**没有多标记联合回归**——两 loci 每碱基率差 1.7× 且显著，被当作"基因组不均匀"的证据报告。详见下方对照表 |
| WGS 真值 | **Lee, Popodi, Tang & Foster 2012**, *PNAS* 109:E2774, `10.1073/pnas.1210309109` | WGS 直接测全基因组每碱基速率；换算结果最终要与这类数对上 |
| 同株配对 | **Takemoto et al. 2018**, NAR `10.1093/nar/gky481` | 同一株波动（Rif 8.2×10⁻⁹/代）÷ MA-WGS（1.1×10⁻⁹/bp/代）⇒ `T_eff(Rif) ≈ 7 bp 当量`——本工具默认 `T_eff≈7` 的实测出处；其 dnaE(D647G) 突变位于 PHP 域 |
| 均匀性边界 | **Jee et al. 2016**, Nature 534:693, `10.1038/nature18313`（✅ 本地）；**Dillon et al. 2016**, MBE `10.1093/molbev/msw224`（✅ 本地） | 位点间每碱基速率差 **≥10×**——单点标定的 M 只是一阶估计（2–10× 偏差），必须带误差棒 |

**外部对照**：Tanneur 2025（`10.1093/nar/gkaf147`）用 MA-WGS 直接测得 PHP 域缺陷
mutator 的全基因组置换率 5.5×10⁻⁸/bp/代——这类已发表 WGS 速率是换算结果最硬的对照，
自标定完成后应与其对量级。F 的跨位点可移植性必须按位点逐一验证
（Jee 2016 / Dillon 2016 的 ≥10× 均匀性边界）。

**适用范围提醒**：`M` 只进**乘客支路**；`f_step`（供给）用目标药实测，不经过任何
位点→基因组换算；窗口推荐对 `M` 整体缩放不变（`knowledge-base.md` §2.2）。
标记必须是**单拷贝蛋白靶标**（rpoB/rpsL 类）；rRNA 靶标拷贝数因属而异，
不能按 `T_eff` 外推。
