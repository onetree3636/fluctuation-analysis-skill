# 术语表（零基础版）

> 每个词一句话、给单位、告诉你它在哪个命令里出现。看文档卡住时先查这里。

## 一、实验设计相关

| 术语 | 一句话 | 单位 | 出现处 |
|---|---|---|---|
| **波动分析** | 用多管突变体数的**分布**估突变速率的方法（Luria–Delbrück 1943） | — | 全篇 |
| **克隆数** | 独立突变**事件**数（期望 m，Poisson），**不是**菌落数 r | 个 | 原理 |
| **克隆大小** | 一个克隆包含的细胞数（打散成单细胞后，≈它贡献的菌落数）；早期突变→大克隆 | 个 | 原理 |
| **C** | 平行培养的管数（"铺多少管"） | 管 | `design-induction`、`power` |
| **N₀** | 起始接种的细胞数 | CFU | 实验设计 |
| **Nt** | 培养结束时每管的细胞数 | **CFU/管**（不是 CFU/mL！） | `rate` 输入 |
| **m** | 每管发生的突变事件数（期望值） | 个/管 | `rate` 输出的核心量 |
| **μ** | 突变率：每个细胞每次分裂发生突变的概率 | per CFU per passage | `rate` 输出 |
| **M** | 每个基因组每代累积的乘客突变数 | per genome per generation | 窗口优化（strain card） |
| **p₀** | 零突变管的占比 | 比例 | `rate` 的交叉核验 |
| **jackpot** | 一个超大的突变克隆（早期突变造成），会让计数很大 | 个 | 数据里 r 特别大的管 |

> **最容易混的三个**：m（每管事件数）、μ（每细胞每次分裂）、M（每基因组每代）。
> 波动分析报 μ；窗口优化用 M。**两者别直接比大小。**

## 二、统计相关

| 术语 | 一句话 | 出现处 |
|---|---|---|
| **MSS-MLE** | 目前最准的估速方法（用全部数据做极大似然） | `rate` 默认 |
| **95% CI** | 95% 置信区间：真值有 95% 概率落在里面 | 所有输出 |
| **profile-LR CI** | 一种 CI 算法（rSalvador 也用这个），比老方法更准 | `rate` |
| **LRT** | 似然比检验：判断两批速率是否有显著差异 | `compare` |
| **fold-change θ** | 两批速率的倍数（θ=2 就是 2 倍） | `compare` |
| **功效** | 真存在差异时，实验能检出的概率（通常要 ≥0.9） | `power` |

## 三、诱导剂与窗口相关

| 术语 | 一句话 | 单位 | 出现处 |
|---|---|---|---|
| **C50** | 半饱和剂量：突变率达到最大增幅一半时的诱导剂浓度 | mM | `fit-induction`、`design-induction` |
| **Δsat** | 饱和时突变率的总增幅 = A·ψ(1)（linear 下才等于 ΔM·q） | 每基因组每代 | `fit-induction` |
| **q** | 表达能转化成"占位"的最大比例（≤1） | — | `fit-induction`（弱可辨） |
| **mixing** | 突变酶与野生型酶在复制体里的混合方式（linear / two_core / both_core） | — | `fit-induction` |
| **τ_on / τ_off** | 诱导开启 / 关停后的活性时间常数 | 小时 | `fit-tauoff`、strain card |
| **plasmid_loss_per_gen** | 温敏质粒每代丢失（稀释）比例，0.5=每代减半 | — | protocol card |
| **events** | 独立突变事件数（决定能筛到几个克隆） | 个 | `optimize` 报告 |
| **E[P]** | 每克隆的期望乘客突变数（要压低的量） | 个 | `optimize` 报告 |
| **参数不确定性** | 你测的每个参数本身的误差传播出来的区间 | 个 | 报告 §4 第一条 |
| **克隆间离散** | 同一批里不同克隆天生的差异（σ_ln，默认 1.0）；**补测参数也不会收窄** | 个 | 报告 §4 第二条 |
| **边界解** | 推荐值顶在网格端点（剂量/T/N₀ 已用到上限） | — | 报告 §1 的 ⚠ |
| **乘客突变** | 与目标表型无关、被 mutator 顺带引入的突变 | 个 | 窗口优化 |
| **passenger_scale** | 单位点速率 μ → 全基因组每代 M 的折算因子（10⁵–10⁶，需 WGS 校准）；只影响绝对乘客数/误伤概率，不影响窗口推荐 | — | strain_card |

## 四、误伤/保护区相关（v0.5）

| 术语 | 一句话 | 出现处 |
|---|---|---|
| **保护区** | 不希望被打中的区域：mutator 自身、产物基因簇、开关区 | strain_card `protected:` |
| **f（占比）** | 该区占细胞总 DNA 的比例 = 拷贝数×长度/总 DNA | 报告 1b |
| **误伤概率 P(≥1)** | 整个窗口内该区至少被打中一次的概率 | 报告 1b |
| **误伤预算** | 能接受的 P(≥1) 上限（如 5%） | 报告 1c |
| **genome_mb** | 基因组大小（Mb），用户按菌株填 | strain_card |
| **plasmids / plasmid_kb+copies** | 载体的总大小与拷贝数（名称随意）；单质粒可用简写 | strain_card |
| **必填参数** | 菌株卡的 10 项与协议卡的 5 项；缺一项直接报错，不会用默认值替代 | `optimize` |
| **status: measured / assumed / literature** | 参数出处；assumed 会在报告里标 ★未测 | strain_card |
| **selection: silent / lethal** | silent=被打中会静默留在克隆里（真乘客）；lethal=在抗生素选择压下被淘汰（只影响产量） | strain_card `protected:` |

## 五、输入格式相关

| 术语 | 一句话 |
|---|---|
| **r** | 该管数到的抗性菌落数（整数） |
| **Nt** | 该管终末细胞数，**CFU/管** |
| **volume_mL** | 培养物体积（mL）。若 Nt 是 CFU/mL，加这一列会自动换算 |
| **fraction-plated ζ** | 只涂了一部分培养物时的涂板比例（整管=1） |
| **per_tube** | 逐管 Nt 校正模式（各管 Nt 不一致时用） |
