# 活菌计数不准时怎么办（波动分析专用）

> 波动分析的 μ = m / Nt：`m` 来自 r 的分布，`Nt` 是每管**可繁殖单元**数。Nt 不准，绝对 μ 就不准；
> 如果计数单位不是"单细胞"，连 `m` 都会偏。本文按**六种情况**给诊断与校正/替代方案。

## 0. 先分清两件事

| 符号 | 含义 | 不是什么 |
|---|---|---|
| **ζ（fraction plated）** | 你**只涂了整管培养物的多大比例**（如 0.1/2 mL = 0.05） | 对应的 Nt 是**整管总 CFU** |
| **e（plating efficiency / recovery）** | 一个**可繁殖单元**涂到非选择性板上能长出菌落的概率 | 对应的 Nt 是**真实总细胞数**（显微/流式校准），不是 CFU |

> `--fraction-plated` 在数学上是"每个突变细胞被检出/被涂上的概率"，ζ 和 e 都能用它建模；
> **关键是 Nt 的口径要配对**：用 ζ 时 Nt=整管总 CFU；用 e 时 Nt=真实总细胞（否则会重复校正）。
> 实操上更稳的是：报 **per-CFU** 速率 + 相对倍数 F，而不是硬把 e 塞进模型。

## 1. 六种情况速查

| # | 情况 | 典型现象 | 对 μ 的影响 | 首选对策 |
|---|---|---|---|---|
| A | **随机误差大** | 同一样品各板/各管 Nt 差 2–5 倍 | 方差变大，点估计不一定偏 | 逐管 Nt、3 板/管、增加 C |
| B | **系统性低回收（e<1，WT/突变体一致）** | 显微总数 ≫ CFU；稀释线性但斜率低 | 绝对 μ 偏（方向取决于口径）；**F 近似保留** | 测 e；报 per-CFU；相对比较优先 |
| C | **WT 与突变体回收不同** | 抗性菌落小/长得慢；混合涂板比例失真 | r 偏低 → μ 偏低 | spike-in 校正；换标记；缩短培养 |
| D | **计数单位不是单细胞（团块/链/菌丝）** | 超声后 CFU 上升；镜检见团块 | **m 也偏**（克隆大小分布变形） | 打散到单细胞；打不散只报 per-CFU |
| E | **平板长不出来（VBNC/特殊营养/生物膜）** | 显微有菌、平板无菌；回收率极低 | Nt 与 r 同时低估 | MPN、qPCR、流式；或改培养条件 |
| F | **计数超出可数范围** | 板上 0 或 >500、稀释梯度不线性 | Nt 误差大 | 多稀释度、3 板、MPN |

## 2. 逐种情况：诊断 + 校正

### A. 随机误差大

- **诊断**：同一管涂 3 块板，板间 CV；同批多管 Nt 的 CV。
- **校正**：每管 3 块板取均值；逐管测 Nt（`--nt-mode per_tube`）；C 按 m 加大。
- **报告**：写清 Nt 的 CV；CV>20% 时不要只报一个 μ 点估计。

### B. 系统性低回收（e<1，但 WT 与突变体一致）

- **诊断**：
  1. 显微总计数（DAPI/SYBR Green）或流式 vs CFU → `e = CFU / 显微计数`；
  2. 稀释线性：同一培养物 3 个稀释度，CFU 应成正比；
  3. spike-in：加入已知数量的标记菌，测回收。
- **校正**：
  - 若只关心 **mutator vs WT 的倍数 F**：同标记、同批、同计数口径，e 在两边近似抵消，**优先报 F**；
  - 若要绝对 μ：用 e 校正 Nt（`Nt_true = CFU / e`），但注意 r 也受 e 影响；严格处理需把 e 纳入似然（`--fraction-plated e`，且 **Nt 必须是真实总细胞**，不能是 CFU）；
  - 实操上最稳：**报 per-CFU 速率**，并注明"未校正回收率 e≈…"。
- **报告**：`μ = … per CFU per passage（e 未校正，e≈0.3）`；跨文献只比倍数。

### C. WT 与突变体回收不同

- **诊断**：WT 与 Str^R 突变体按已知比例混合涂板，看回收比例是否偏离；比较菌落直径/出现时间。
- **校正**：
  - spike-in 内标：向每管加入固定数量的、可区分的参考菌，按回收率校正 r 与 Nt；
  - 换标记（选菌落大小/生长更接近 WT 的标记）；
  - 缩短培养、早计数，减少慢生长突变体被压。
- **报告**：若无法校正，明确写"突变体回收率可能低于 WT，μ 可能偏低"。

### D. 计数单位不是单细胞（团块/链/菌丝）

- **诊断**：
  1. 镜检（相差/DAPI）看团块；
  2. **超声时间–CFU 曲线**：0/5/10/20 s，CFU 上升后平台；
  3. 超声后存活率（与未超声对照）≥80%。
- **校正**：
  - 固定打散 protocol（冰上 3×5 s，或匀浆），每次实验都用同一套；
  - 打散后镜检单元 ≤2–3 µm；CFU 平台即"单细胞/单CFU"；
  - 打不散：把 μ 定义成 **per CFU per passage**，只比倍数；不要跨文献比绝对值。
- **报告**：写"超声 3×5 s，存活率 x%；μ 为 per CFU per passage"。

### E. 平板长不出来（VBNC/特殊营养/生物膜）

- **诊断**：显微/流式有大量活菌，但 CFU 极低；换培养基/延长培养/加信号分子仍不升。
- **替代计数**：
  1. **MPN**（最大或然数）：适合低浓度、液体稀释；但精度依赖稀释度与管数；
  2. **qPCR（单拷贝基因）**：给"基因组当量"，不是可培养单元；用于总量参考；
  3. **流式（SYBR/PI 或活/死染色）**：给总细胞/活细胞，需与 CFU 校准；
  4. 生物膜：超声/涡旋/玻璃珠打散后再计数。
- **注意**：L-D 模型要的是"能形成菌落的繁殖单元"；qPCR/流式的总数不能直接当 Nt，除非证明与 CFU 有稳定比例。
- **报告**：用 CFU 为主，qPCR/流式作正交验证；若只能用 qPCR，明确写"μ 为 per genome equivalent，非 per CFU"。

### F. 计数超出可数范围

- **诊断**：板上 0 或 >500；相邻稀释度不成比例。
- **校正**：每管 3 个稀释度 × 3 板；选 30–300 的板；必要时 MPN；`rate` 的 Nt 取多板均值。
- **注意**：r 的上限 5000 是引擎硬限制；Nt 的计数上限要靠稀释解决。

## 3. 三个通用诊断实验（建议先做）

| 实验 | 做法 | 判据 |
|---|---|---|
| **显微 vs CFU** | DAPI/SYBR 计数总细胞；同一样品涂 CFU | e = CFU/显微计数；e<0.5 要警惕 |
| **超声时间–CFU** | 0/5/10/20 s 超声，各涂 3 板 | CFU 出现平台；存活率 ≥80% |
| **spike-in 回收** | 已知量标记菌加入样品，混合涂板 | 回收 80–120% 为可接受 |

## 4. 对波动分析结果的影响（怎么报）

| 情形 | μ 绝对值 | F（mutator/WT） | 建议 |
|---|---|---|---|
| A 随机误差 | 方差大 | 可用 | 逐管 Nt + 加 C |
| B 低回收、两边一致 | 偏（需 e 校正） | 近似保留 | 报 per-CFU + e；优先 F |
| C 两边回收不同 | 偏 | 偏 | spike-in 或换标记 |
| D 团块/链 | m 也偏 | 偏 | 打散；否则只报 per-CFU 倍数 |
| E VBNC | Nt 低估 | 可能偏 | MPN/qPCR/流式；CFU 为主 |
| F 超范围 | 误差大 | 可用 | 多稀释度 |

**报告模板**：
```
Nt 口径：CFU/管（整管涂板；未校正回收率 e≈0.3）
μ = 5.1e-9 per CFU per passage（95%CI …）
注：若按显微总细胞校正，per-cell 速率约 …；跨文献只比倍数。
```

## 5. 技能里怎么用

- `rate`：Nt 填**你信任的口径**（CFU/管）；逐管 Nt 用 `--nt-mode per_tube`；
- 用 `--fraction-plated` 时想清楚 Nt 口径：ζ → 整管总 CFU；e → 真实总细胞（显微/流式校准）；二者不能混；
- 只关心差异：用 `compare`，同标记、同批；
- 做窗口：`optimize` 的 events 是"每 CFU 的事件数"；μ_supply 与 Nt 必须同口径；
- 报告里必须写 Nt 口径、e 是否校正、是否 per-CFU。

## 6. 一句话

**Nt 不准时，先分清是"随机误差、低回收、回收不一致、团块、VBNC 还是超范围"；能打散就打散，能测 e 就测 e；绝对 μ 谨慎，倍数 F 优先。**
