# mutator 使用指南：表达窗口计算（把乘客突变压进预算）

> 目标不是"让 mutator 多强"，而是回答：**开多久、开多强、从多少细胞起开**，
> 才能在拿到 k 个独立抗性克隆的同时，让每个克隆的乘客突变 ≤ 预算。
> 工具：`windowcalc optimize`（+ `fit-fc` / `fit-tauoff` 提供连续剂量与衰变尾）。
> **示例标记**：下文用 Rif/rpoB（测速）与 Str/rpsL（供给端）作示例；换成其他标记时公式不变。
> 菌株卡字段 `mu_supply` 指"供给端标记"的速率（与具体药物无关）。

## 1. 为什么需要"窗口"而不是开关

乘客突变**逐相位累积**，不止在脉冲期：

| 相位 | 诱导状态 | 负荷贡献 |
|---|---|---|
| 接合后恢复/预培养 | off（泄漏） | n₀ × M_off |
| 诱变脉冲（含上升沿 τ_on） | on | n_pulse × M_on |
| 洗脱衰变尾（τ_off） | on→off | 蛋白不降解就持续突变 |
| 选择板菌落长出 | off | ~10–20 代 × M_off |
| 治愈/孢子传代 | off | 2–4 代 × M_off |

全强度 mutator（文献例 gkab583，F≈1000×）实测锚点：约 **3–4 个突变/基因组/代**；一轮 20–27 代 → **66–96 个乘客/克隆**
（gkab583 WGS）。弱 mutator（10–100×）+ 多筛克隆时，off 项与脉冲项同量级。

## 2. 模型：三个方程、两条标度律

```
a(t)：0→1 上升（τ_on），1→e^(−t/τ_off) 衰减（τ_off）
M_on(c) = M_on_ref × [F(c)/F(ref)]        锚定实测 M_on_ref，剂量只给形状比
M(t)    = M_off + (M_on(c) − M_off)·a(t)  每基因组每代乘客突变数

供给  events = Σ_i μ_supply·[F(c_i)/F(ref)]·ā_i·ΔN_i      ΔN = 相位内总分裂
负荷  E[P]  = Σ_i M(ā_i)·n_i                          n = 每世系代数
成功  P = 1 − exp(−events)                           独立事件；jackpot 是假供给
```

**两条标度律（最值钱的输出）**：
1. **供给 ∝ 窗口内总分裂**（≈ Nt − N₀）——培养到饱和，事件数就定了，与脉冲长短基本无关；
2. **负荷 ∝ 每世系经历的代数** n = log₂(Nt/N₀)——**高密度接种是最强降荷旋钮**。

推论：把 F 拉满不增加"有效"供给（超出筛选通量的事件是浪费的负荷），只增加乘客。

### 2.1 剂量轴：为什么用机制模型而不是 F 表（v0.4）

F 表是"黑箱倍数"，可以拟合出任何形状，**没有物理上限**——优化器可能把诱导剂推到
"等效 F=3000"这种物理上不可能的占位。机制模型把它拆成三步：

```
E(c) = Emax·cⁿ/(EC50ⁿ + cⁿ)        表达（Hill）
p(c) = E(c)/(E(c)+K) = q·h(c)      竞争占位（Langmuir；q = Emax/(Emax+K) ≤ 1）
M(c) = M_off + ΔM·φ(p)             速率
```

`φ` 是复制体组成：`linear`（φ=p）、`two_core`（φ=2p−p²，一个核心够）、`both_core`（φ=p²）。

**可辨识性**：从突变率数据只能稳健定出 `Δsat = A·ψ(1)`（有效占位幅度；linear 下才等于 ΔM·q）、C50、n；
q 与 ΔM 不可分（`two_core` 下 q 弱可辨），所以**不要**把 Δsat 当"占比 p"用。

**它带来两个直接有用的输出**：
1. M(c) 有上限——超过饱和点再加诱导剂只增负荷、不增有效供给；
2. **95% 饱和剂量**——报告会直接标"当前剂量处于 X% 饱和"。

```bash
windowcalc fit-induction --input 剂量.csv --m-off 0.012 --query 0.05 0.5 5
```

## 3. 三个旋钮与约束

| 旋钮 | 范围 | 作用 |
|---|---|---|
| T_pulse | ≥ τ_on + 0.5 h | 时长：主要抬负荷 |
| c（诱导剂） | 可用剂量点 / F(c) 曲线 | 强度：抬供给也抬负荷 |
| N₀（接种/涂板量） | N₀_min–N₀_max | 决定总分裂（供给）与代数（负荷） |

约束：P(events ≥ k) ≥ 0.95；T ≥ τ_on + 0.5 h；N₀ ≤ N₀_max。目标：**min E[乘客]**。

## 4. 需要哪些参数

| # | 参数 | 用途 | 来源 |
|---|---|---|---|
| 1 | M_base | 泄漏红线（M_off ≤ 3×M_base）**与量级锚点** | **WGS/基因组折算**（Drake 0.004 量级）；选择标记波动给的 μ 只能用于比值 |
| 2 | M_on_ref | 脉冲项锚点 | 波动分析（mutator-on） |
| 3 | M_off | off 相位负荷 | 波动分析（mutator-off） |
| 4 | td（±诱导） | 代数换算 | 生长曲线 |
| 5 | **τ_off** ★ | 衰变尾——**最可能推翻设计** | 洗脱 0/2/4/8/16 h 的速率衰减 |
| 6 | **μ_第二标记@选定浓度**（字段 `mu_supply`）★ | 供给端主参数 | 波动分析换第二标记的选择板（示例：Str，5–10× MIC） |
| 7 | **剂量轴** | 剂量连续化 + 饱和点 | ≥3 个浓度 → `fit-fc`（F 表）；**≥5 个且跨膝点 → `fit-induction`（机制模型，推荐）** |

**★ M 的量纲（最容易错的一处）**：`M_base / M_on / M_off` 是**全基因组每代**的乘客突变数
（示例卡 0.004 = Drake 的基因组值；全强度 mutator（文献例）实测 3–4/基因组/代）。
`windowcalc rate` 输出的是**单位点**速率 μ（如 rpoB/Rif，~1e-9），**不能直接粘进 M_***——
差 10³–10⁶ 倍。M 的来源只有三条：① **WGS 数乘客**（gkab583 式，最硬）② 用 `passenger_scale`
把单位点速率折算成全基因组口径（经验比值 **10⁵–10⁶**，需校准）③ 同源菌文献值。
只有**比值**（M_off/M_base、F）可以在 μ 的量纲下直接算。

⚠ **不要按"基因组长度/基因长度"折算**：标记抗性通常只由靶标上少数热点产生（如 Rif→rpoB 的几十 bp），
有效靶标远小于基因长度——以 rpoB 为例长度比 ~2×10³，而实测速率比 ~10⁵–10⁶，中间差的 10²–10³ 倍
用长度补不回来（按长度折算会把 M 低估约 500 倍，仍然得出"零乘客"）。

**拿不到 WGS 时怎么用**：在卡片里加
```yaml
passenger_scale: {value: 1.0e6, ci: [3.0e5, 3.0e6], status: assumed,
                  note: "标记位点→基因组的经验比值（示例：Rif）；用自家 WGS 对子校准后改 measured"}
```
它会乘在**绝对负荷**上（乘客数、误伤概率），并自动成为 tornado 的**第一行**——
它的作用不是"猜一个数"，而是回答"绝对风险到底取决于这个因子到什么程度、现在值不值得去做 WGS"。
校准方法：同一株同时测选择标记的波动分析（得 μ）与 WGS 数乘客（得 M），两者之商就是因子。
**窗口推荐（剂量/T/N₀）与该因子无关**（前提：只约束事件数、没有绝对乘客上限；若设了硬乘客预算，尺度会改变可行性），报告里会写明这一点。

软件会在 `M_* < 1e-5` 且**没有** `passenger_scale` 时打**红灯**（"看起来是单位点速率"）；
给了因子则降级为"警示：已按 X 折算，该因子是假设值"；`rate` 的输出片段也会标注。

**必填 vs 可选（2026-10-29 起强制执行）**：

| 类别 | 字段 | 缺了会怎样 |
|---|---|---|
| **必填·菌株卡** | M_base / M_on_ref / M_off / μ_supply / τ_on / τ_off / td_on / td_off / Nt_saturation / ref_dose | **直接报错**，并列出全部缺失项 |
| **必填·协议卡** | `decision` 的 k_target_clones / P_success_min / T_pulse_range_h / N0_min / N0_max | **直接报错** |
| 可选但会告警 | background_false、clone_dispersion_sigma_ln、genome_mb+protected、剂量轴、**passenger_scale** | 计算继续，stderr 明示"用了什么默认/没算什么" |

只有假设值也能跑，但要**显式**写 `status: assumed`——报告会把它标成 ★未测；
这与"静默默认"是两回事：前者留在报告里被人看见，后者被藏起来。

**结构参数也能带 CI**（`td_h_on: {value: 2.5, ci: [2.0, 3.0], status: measured}`）——
它们决定代数 n，是负荷的一阶驱动量。带 CI 就进 MC 与 tornado；不带则按**常数**处理。

**MC 到底传播了什么（报告 §4 会写明）**：
- 传播：M_off / μ_supply / τ_on / τ_off（有 CI 用 CI，没 CI 按 ±2× 对数正态假设）、
  剂量轴的 A/C50/n（在 `inducer.ci` 给了区间时）、td/td/Nt_saturation（带 CI 时）；
- **不传播**：F(c) 表本身的形状不确定度（只对 M_on_ref 采样）、克隆间离散（单列成第二个区间）。

缺实测就显式写 `status: assumed`，报告会标 **"★未测"**；`参数实测率 0/N` 时结论只能当占位——如实转告，不要当预测。

### 4.1 没有诱导剂怎么办（组成型表达）

不是所有 mutator 都有浓度梯度。软件在这种情况下照样能用，但要分清**还剩几个旋钮**：

| 情形 | 可用旋钮 | 窗口还有意义吗 |
|---|---|---|
| 有诱导剂梯度（如纤维二糖） | T_pulse × c × N₀ | 有，三旋钮 |
| 组成型表达，但**有时序开关**（温度敏感、降解标签、可洗脱） | T_pulse × N₀ | **有**，两旋钮——开关仍在，只是强度不可调 |
| 组成型表达，**全程开启**（无任何开关） | 只有总分裂数 | **没有比例可优化**：事件与乘客同比例增长，每事件乘客 ≈ (M/μ_supply)·(n/ΔN) ≈ M/(μ_supply·Nt) |

第三种的正确用法：
1. 报告会自动标注「剂量轴：无（恒定表达）」，并给出 **⚠️ 无开关窗口**：每事件乘客按分母算清楚（= (M/μ_supply)·(n/ΔN) ≈ M/(μ_supply·Nt)，**不是** M/μ_supply）；
2. 此时"优化"唯一能做的是：在满足 `P(events≥k)` 的前提下把**总分裂数压到最低**（早收获、少代数）；
3. 若算出的「每事件乘客」× k 不可接受（例如 0.09 × 12 事件 = 1.1 个乘客），那不是窗口问题，
   而是 **mutator 太强或选择标记太少**——该换弱 mutator、换标记，或降低目标克隆数。

操作上：`strain_card` 不给 `inducer` 块、`protocol_card` 的 `doses_available` 留空即可，
优化器自动退化成 T × N₀ 两维网格；失败诊断也不会再建议"加诱导剂"。

### 4.2 双开关构型（诱导启动子 + 温敏质粒）

如果 mutator 同时有**严谨型诱导启动子**和**温敏型质粒**，关停有两条腿：移除诱导剂（启动子关）
＋ 升温（质粒不再复制，随分裂稀释出）。模型里对应三个相位：

| 实验动作 | 相位类型 | 模型怎么算 |
|---|---|---|
| 许可温度 + 诱导剂，生长 | `pulse` | M(c) = M_off + A·ψ(h(c))，A = Δsat/ψ(1)（linear 时 A = Δsat）；供给 ∝ activity |
| 去诱导 + 升温，蛋白尾期 | `decay` | 活性 a(t)=exp(−t/τ_off)，负荷按 a 加权 |
| 限制温度继续培养，质粒稀释 | `off` + `plasmid_loss_per_gen` | 泄漏 M_off 按 (1−loss)ⁿ 衰减 |
| 选择板 | `off` | 泄漏已接近地板 |

**必须按"真实切换条件"测的两个参数：**

1. **τ_off**：在"去诱导 **+** 升温"同时发生的条件下测（0/2/4/8/16 h 的速率衰减）。
   只测去诱导会**高估**有效窗口——质粒稀释那一条腿没被算进去；
2. **M_off 地板**：质粒治愈后（限制温度培养 ≥4 代）的速率，作为 off 相位的残余泄漏。
   若直接用在许可温度下测的 M_off，会**高估**尾期负荷。

**未测时的保守约定**：τ_off 取**稀释上界 1.44×td**（用限制温度下的 td），CI 写 [0.5, 1.44·td]
（下界对应加了降解标签的情形）；报告用 MC 传播这个区间。只有乘客预算卡在边界上时才需要实测
（算法：残存蛋白项 ≈ (M_on−M_off)·τ/td）。

**拷贝数 → 治愈代数**：复制停止后，每分裂一代拷贝数减半，稀释到 <1 需要 `ceil(log2 N)` 代。
`N` 是**你质粒的拷贝数**，由用户提供（qPCR/测序/文献，并注明来源）——本技能不预设任何质粒；
例：N=20 → 5 代，N=50 → 6 代。

**限制温度**：按你质粒的温敏特性给（常见 37–39 °C，但以实测为准，不要套用别的质粒）。

**质粒丢失速率 `plasmid_loss_per_gen`：**
- `0.5` = 每代减半（无主动分配的纯稀释，温敏质粒的常见上限）；
- 有主动分配/更稳的质粒取更小；有主动治愈可更大；
- 实测：切换后每代同时涂"含质粒标记"板与非选择板，得含质粒细胞比例 → 拟合 (1−loss)ⁿ。

**治愈代价（可以直接心算）**：治愈 c 代的总乘客 ≈ M_off · ((1−loss)^c − 1) / ln(1−loss)。
例：loss=0.5、c=4 → ≈ **1.35·M_off**；同样 4 代若质粒不丢则是 4·M_off。
所以"治愈几代"要显式建模——它既不是零成本，也不该按全泄漏计价。

**抗生素的时机（容易踩的坑）**：诱导窗口内加质粒选择抗生素是**有利的**——它维持质粒与
mutator，防止窗口内丢质粒；但**治愈期（限制温度）必须撤掉抗生素**，否则质粒-free 细胞被杀死，
治愈等于失败。选择板上的抗性也必须是染色体编码的，不能依赖已丢失的质粒。

**哪些"保护区"其实不用护**：抗性基因、复制子这类**在抗生素选择压下**的区域，被打中会在
窗口内被淘汰，不会进入最终克隆——它们影响的是产量（且多拷贝下功能丧失概率 ~1e-52），
不是克隆质量。真正要护的是**单拷贝的产物基因簇**和**开关区**。strain_card 里用
`selection: silent | lethal` 区分，报告会分"克隆质量风险"与"产量风险"两栏。

**升温的第二个效应**：限制温度下生长变慢（td 变大）。相位里要写 `td_h`，否则代数算错。
好处是每小时经历的代数更少，负荷积累更慢——双开关在这点上优于单开关。

**模板**：`examples/protocol_card.dual_switch.example.yaml`（预培养 → 脉冲 → 切换 → 治愈 → 选择板 → 传代）。

## 5. 怎么跑

```bash
# ① 先算速率（WT / mutator-off / mutator-on 各一组）
#    ⚠ 这里得到的是**单位点** μ：能直接填的是"比值"（M_off/M_base），
#      绝对负荷要另用 WGS 折算成全基因组的 M（见 §4 的「M 的量纲」）
windowcalc rate --input wt.csv --label M_base --field M_base --nt-mode per_tube
windowcalc rate --input m7on.csv --label M_on_ref --field M_on_ref --nt-mode per_tube

# ② 拟合剂量响应与衰变尾（有数据后）
windowcalc fit-fc --input dose.csv --mu-base <M_base> --query 0.05 0.3 1.0
windowcalc fit-tauoff --input washout.csv --mu-off <M_off> --td 2.5 --m-on <M_on>

# ②b 先设计剂量轴（不知道 C50 也行；卡里有 c50 就 --strain）
windowcalc design-induction --strain strain.yaml --ref-m 6
windowcalc design-induction --n-doses 4 --range 0.03 3

# ③ 填 strain_card / protocol_card（examples/ 有模板）
#    注意 type 必须加引号（YAML 1.1 把裸 off/on 当布尔）

# ④ 出窗口
windowcalc optimize --strain strain.yaml --protocol protocol.yaml --out 报告.md
```

**strain_card 关键字段**：M_base / M_on_ref / M_off / mu_supply / background_false / τ_on / τ_off /
F_doses / ref_dose_mM / td_h_off / td_h_on / Nt_saturation / clone_dispersion_sigma_ln。
每个参数可带 `value: CI: status: measured|assumed|literature`。

**protocol_card 关键字段**：phases（pre / pulse / decay / off，各给 duration_h 或 generations、N0/Nt），
decision（k_target_clones、P_success_min、T_pulse_range_h、N0_min/max、doses_available、mc_samples）。

### 6.0 窗口的两层约束（保护优先）

窗口不是"越大越好"，而是两层约束的交集：

1. **下限**：用户期望的 k 个独立事件 → 窗口太短拿不到；
2. **上限**：质粒上的 mutator（自失活）+ 基因组上的保护区（不希望引入突变的簇）→ 窗口太长会超限。

**保护是硬上限，而且分两条独立上限。** 协议卡里：

| 字段 | 默认 | 管什么 |
|---|---|---|
| `P_protected_max` | **0.10** | BGC/其他保护区（`role: bgc` 或 `other`）被误伤的概率 |
| `P_mutator_max` | **0.05** | mutator 自失活（`role: mutator`，如 mutator 编码区 × 拷贝数）的概率 |

当"拿到 k 个事件"所需的窗口会超过**任一条**上限时：

- `optimize` **按上限截断窗口**（在两条上限内取 events 最大的方案），不越界；
- 报告写清是哪条 binding：`⛔ 保护上限 binding` + 实际 `E[events]`、与目标 k 的**缺口**、`P(≥k)`；
- 补缺口的方向：降 k / 提高 N₀ / 换更大选择靶标 / 改用局部编辑——**不是**加长窗口；
- 若连最短窗口都超上限，报告 `⛔ 保护上限不可行`，应先缩短必须分裂的阶段、降低 M_off 或换更安全的构型。

`protected` 里用 `role` 区分：`role: mutator` 算进 mutator 上限；`role: bgc` / `other` 算进保护区上限。不写 `role` 默认 `other`。

### 6.1 保护区账本（v0.5）：把"乘客"换成"误伤概率"

在 strain_card 里配三样，报告会多出 1b / 1c 两节：

```yaml
genome_mb: 8.4                     # 按菌株填
plasmids:                          # 你们的载体（名称随意/可省略）
  - {name: 载体, kb: 16.0, copies: 20}
# 单质粒也可简写：plasmid_kb: 16.0 / plasmid_copies: 20

protected:
  - {name: "产物基因簇",   kb: 22,  copies: 1,  selection: silent, role: bgc}
  - {name: "mutator 编码区", kb: 3.5, copies: 20, selection: silent, role: mutator}
  - {name: "抗性基因",     kb: 1.0, copies: 20, selection: lethal}
  - {name: "复制子",       kb: 2.0, copies: 20, selection: lethal}
```

`role` 只有三个取值：`mutator`（算 mutator 自失活上限）、`bgc` / `other`（算保护区误伤上限）；不写默认 `other`。

- **1b 账本**：每个保护区的占比 f、期望命中、P(≥1)，以及"任一保护区"的合计概率；
- **1c 预算表**：在 1%/2%/5%/10%/20% 各档预算下，能达到的最优方案（T/剂量/N₀/events）。

**数学**：`f = 拷贝数×长度 / 总 DNA`；`E = 乘客×f`；`P(≥1) = 1−exp(−E)`。
假设突变在 DNA 上均匀分布——热点、序列偏好不在模型内。

**两个必须知道的事实**：

1. 因为 f 对所有候选方案相同，**按"保护区命中"排序与按"总乘客"排序是同一个顺序**；
   真正改变结论的是**预算是否可行**（1c 表里出现"无可行解"）与把风险摆到明面上；
2. 窗口本身不改比值 `events/保护区命中 = (μ_supply·ΔN)/(M·n·f)`——要改善它，得换更大的选择靶标
   （如 Rif/rpoB 4.5 kb vs St/rpsL 0.4 kb，约 10 倍）或缩短"必须分裂但不需要诱变"的阶段。

示例（占位参数，基因组 9 Mb + 载体 16 kb×20、BGC 100 kb、当前方案 6.8 乘客）：
BGC 误伤 **7.0%**、mutator 编码区（3.5 kb×20）**5.0%**、"任一保护区（静默区合计）" **11.7%**；
预算 ≤10% 时无可行解，≤20% 可拿到 12 个事件。（这几个数可以用 §5 的 `protected_hits` 直接复算。）

**反过来：想打中 BGC（而不是避开它）**：同一个 `f` 也能算目标命中概率
`P_target(≥1) = 1−exp(−E[P]·f_target)`。BGC 越小越难——100 kb / 8.4 Mb ≈ 1.2%，
要 90% 命中需 ≈190 个乘客，通常超出预算。所以全基因组 mutator 适合"广撒网 + 表型筛选"，
不适合"精准打一个小簇"；后者用局部诱变/编辑，或把靶标扩大到调控区。当前模型把 BGC 记在
`protected`（误伤风险），目标命中概率需用上式另算。

| 节 | 看什么 | 判据 |
|---|---|---|
| 1 推荐方案 | events、P(≥k)、E[乘客]、MC P5–P95 | events 够 k 且 E[P] 最小；P5 太差说明参数没测 |
| 2 时刻表 | 各相位 ā、n、M_eff、乘客贡献 | 找出负荷最大相位（脉冲 vs off 泄漏） |
| 3 标度律读数 | ΔN、脉冲项 vs off 项 | 若 off 项 >20% 脉冲项，静态公式 E[m]=n·M 低估 |
| 4 蒙特卡洛 | E[P] 与 events 的 P5/P50/P95 | 区间宽 = 参数不确定性主导，先去测 |
| 5 tornado | 哪个参数把结果拉得最宽（**只列模型真在用的参数**） | 优先测最宽的那条 |
| 6 红灯/警示 | 见下（引擎 `flags` 全集，共 5 类 + 1 个终止态） | 任一红灯未解决，窗口数字无意义 |
| 附录 A | 引擎版本、网格、seed、MC 抽样数、结构参数 | 复现同一份报告用 |

### 报告里可能出现的全部提示（`flags` 全集）

| 类型 | 触发条件 | 含义 |
|---|---|---|
| 🔴 红灯 | M_off > 3×M_base | 泄漏超标：关不掉的背景突变，off 相位继续积累乘客 |
| 🔴 红灯 | b·N_plated > events | 背景假抗性淹没真供给：该药/该浓度不可用 |
| ⚠️ 警示 | τ_off > 6 h | 有效窗口远大于名义脉冲：此时"脉冲时长"不可信 |
| ⚠️ 警示 | 某剂量无 F(c) 数据 | 按参考剂量 F 计算（参数 7 未测） |
| ⚠️ 警示 | F_doses@ref 与 M_on_ref/M_base 差 >20% | 两组数据应出自同批测定 |
| ⛔ 终止 | 网格内无候选满足 P(events≥k)≥P_min | 输出"无可行解"+ 瓶颈诊断（μ_supply/F/N_plated/背景） |

「参数实测率 n/N」是**可信度提示**（N = 卡里出现的可溯源参数个数，最多 7；td/Nt_saturation/ref_dose 这 4 项结构参数在附录 A 里单列，不算进这个分子分母），不是红灯；但它是 0/N 时，上面所有数字都只是占位。

## 7. 决策规则（该调哪个旋钮）

1. **乘客超预算** → 先缩 T_pulse（负荷 ∝ n，供给 ∝ 总分裂，缩 T 主要减负荷）。⚠ 但 N₀ 与 T 是耦合的：Nt 有饱和上限时，缩短 T 往往要**同时提高 N₀** 才拿得到同样的事件数，而提高 N₀ 又会减少代数——所以别单独看 T，要看优化器给的整组 (T, N₀)；推荐值顶到网格端点时报告会标 **⚠ 边界解**；
2. **供给不足**（events 达不到 k） → 提高 N₀（总分裂↑）或提高 c（F↑），别先拉长 T；
3. **两者都紧** → 降 c + 延 T（弱 mutator 策略），前提是先测 F(c)；
4. **τ_off 未测** → 所有结论只在 ±2 倍内可信（衰变尾可能比脉冲还长）；
5. **红灯优先于优化**：M_off > 3×M_base（泄漏）、b·N_plated > events（背景淹没）→ 先解决再谈窗口。
   τ_off > 6 h 是**警示**不是红灯：它表示有效窗口远大于名义脉冲，此时任何"脉冲时长"都不可信。

## 8. 常见错误

- 把占位假设当实测（看报告的"参数实测率"）；
- 忘记洗脱后的衰变尾——关启动子 ≠ 关 mutator（mutator 蛋白的功能半衰期决定有效窗口）；
- 用单点 F 代表剂量轴（至少 3 点）；
- 按抗性菌落数估"供给"（jackpot 是一个克隆，不是多个事件）；
- 忽略选择板上菌落继续分裂（decay/off 相位的代数）；
- 把 MC 的"含克隆间离散"区间当成"参数没测准"——那一栏补测也收不窄（见 §6 第 4 节）。

## 9. 闭环

先导脉冲（软件给窗口 → 实际跑）→ WGS 3–5 个克隆直接数乘客 → 与预测对比 →
更新 M_on / τ_off / F(c) → 重跑优化。**在闭环完成前，窗口是"模型预测"而不是"实测规律"。**
