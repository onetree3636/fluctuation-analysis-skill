# 标记外推：用一种抗生素测的速率，能不能用到另一种？

> 场景：用户用四环素（或别的药）测了突变率，想把它用到另一个筛选标记上。
> **不能直接把 μ 当目标标记的 μ_supply。** 先按下面的表判断靶标类型，再决定"按比例给先验"还是"必须重测"。

## 1. 先看三件事

1. **靶标是蛋白还是 rRNA？** 蛋白靶标（rpsL/rpsE/rpoB/fusA）通常是单拷贝、点突变；rRNA 靶标（23S/16S）的拷贝数**因属而异**：链霉菌常 5–7（S. coelicolor 为 6），分枝杆菌常 1–2（M. tuberculosis 1、M. smegmatis 2），其他放线菌差异大。
2. **抗性机制是"靶标点突变"，还是"外排/灭活酶/甲基化酶"？** 后者往往由质粒或可移动元件编码，测到的"速率"不是单基因点突变速率，不能按 T_eff 换算。
3. **是不是同一个物种、同一选择浓度？** 换物种/换浓度，抗性谱和背景都会变。

## 2. 常见标记速查（放线菌语境）

| 标记（示例） | 靶标 | 拷贝数 | 主要抗性机制 | 能否从别的标记外推 |
|---|---|---|---|---|
| **链霉素 Str** | rpsL（S12） | 1 | 点突变（K88 等） | ✅ 单拷贝蛋白，可作"per-locus"基准 |
| **壮观霉素 Spe** | rpsE（S5） | 1 | 点突变 | ✅ 同上（T_eff 不同） |
| **利福平 Rif** | rpoB（RNAP，非核糖体） | 1 | 点突变（热点） | ✅ 单拷贝；T_eff≈7 bp（项目口径） |
| **夫西地酸 Fus** | fusA（EF-G） | 1 | 点突变 | ✅ 单拷贝蛋白 |
| **四环素 Tet** | 30S（16S） | 多拷贝 | 常为**外排泵 / 核糖体保护蛋白**（质粒/可移动元件），rRNA 点突变较少 | ❌ 多数情况不是干净的单基因点突变标记 |
| **红霉素 Ery** | 23S rRNA | 5–7（链霉菌） | rRNA 突变（多拷贝、常隐性）或 **erm 甲基化酶**（常质粒） | ❌ 多拷贝/酶灭活，不能按 T_eff 外推 |
| **硫链丝菌肽 Tsr** | 23S rRNA | 5–7（链霉菌） | rRNA 突变 | ❌ 多拷贝 |
| **氯霉素 Cam** | 23S rRNA / CAT | 多拷贝 / 酶 | rRNA 突变或 CAT 乙酰化酶 | ❌ 多数情况不可外推 |
| **卡那/庆大 Kan/Gm** | 16S rRNA / 修饰酶 | 多拷贝 / 酶 | rRNA 突变或氨基糖苷修饰酶 | ❌ 多数情况不可外推 |

> 表是"决策提示"，不是物种定论：先查你菌株的 **rrn 拷贝数** 和已知抗性机制（基因组/文献），再下结论。

## 3. 决策树

```
用户：我用 X 测了速率，想用到 Y
├─ Y 是"单拷贝蛋白靶标 + 点突变"（rpsL/rpsE/rpoB/fusA）
│   ├─ X 也是单拷贝蛋白靶标 → μ_Y ≈ μ_X × T_eff_Y/T_eff_X（只是先验，标 assumed）
│   │     └─ T_eff 不知道 → 先按同量级（比值 0.3–3）做敏感性；仍建议 12 管试点
│   └─ X 是 rRNA/酶/外排 → 不能按比例；把 μ_X 只当"量级参考"，Y 必须实测
└─ Y 是 rRNA（多拷贝）或酶/外排 → 不能外推；必须实测（或换单拷贝标记）
```

## 4. 给用户的话术（必须说清）

- "X 的速率是 **X 这个标记的 per-locus 速率**，不是全基因组速率，也不是 Y 的速率。"
- "Y 如果是单拷贝蛋白靶标，可以按有效靶标比例给一个**先验**，但先验只用来定 C/窗口方向；最终以 Y 的实测为准。"
- "Y 如果是 rRNA/酶/外排，**不能外推**——多拷贝或非点突变机制会让 L-D 的单靶标模型不成立。"
- "不管哪种，先给 Y 做 12 管试点（MIC/背景 + `rate`）；试点成本远低于按错误先验跑完整窗口。"

## 5. 落到技能里

- `rate` 算的是 **μ_locus**（`--field mu_supply` 填的是目标标记）；
- 外推只影响 `mu_supply` 的**先验**（用来定 C / 窗口方向），不改变 `rate` 的算法；
- 外推得到的值必须在卡片里写 `status: assumed` + `note: "由 X 外推，T_eff 比 = …"`，报告会标 ★未测；
- 窗口结论若对 μ_supply 敏感（乘 0.1/10 后窗口大幅移动），先测 Y，不要用先验硬跑。
- 卡片里写 `mu_supply_source: <源标记>` 与 `selection_marker: <目标标记>`；两者不同时 `optimize` 会在 stderr 自动提示外推，报告也会带这条警告。

## 6. 计算过程（可复现）

记：

- `μ_X`：已测标记 X 的 per-locus 速率（per cell per division/passage）；
- `T_eff_X`：X 的**有效靶标**（能产生该表型的碱基当量，**不是基因长度**）；
- `G`：基因组大小（bp）；
- `M`：全基因组每代突变数（per genome per generation）。

两步：

```
① 先换算到全基因组：   M   = μ_X × G / T_eff_X
② 再换算到目标标记：   μ_Y = M × T_eff_Y / G  =  μ_X × T_eff_Y / T_eff_X
```

**例**（数字仅示意，`T_eff` 必须按你的标记校准）：

| 量 | 取值 | 说明 |
|---|---|---|
| G | 8.4×10⁶ bp | 示例基因组 |
| μ_Rif | 5×10⁻⁹ | 假设用 Rif/rpoB 测得 |
| T_eff_Rif | ≈7 bp | 项目口径（gky481 反推） |
| **M** | 5e-9 × 8.4e6 / 7 ≈ **6.0×10⁻³** | 全基因组每代 |
| T_eff_Str | 假设 2 bp | rpsL 热点少，实际需校准 |
| **μ_Str** | 6.0e-3 × 2 / 8.4e6 ≈ **1.4×10⁻⁹** | 即 μ_Rif × 2/7 ≈ 0.29× |

所以外推的核心就是 **T_eff 的比值**：`μ_Y/μ_X = T_eff_Y/T_eff_X`。`T_eff` 错 3 倍，先验就错 3 倍。

## 7. 可信度：单拷贝蛋白靶标之间

| 场景 | 可信度 | 怎么用 |
|---|---|---|
| **同一标记**，mutator vs WT（F） | 高 | 直接报 F；这是最稳的比较 |
| 单拷贝蛋白 → 单拷贝蛋白，同种、同选择浓度、谱相近 | **量级可信（约 3–10 倍）** | 只当先验定 C/窗口方向，标 assumed；最终以目标标记实测为准 |
| 单拷贝蛋白 → 单拷贝蛋白，但 mutator 有明显 indel/谱偏 | 低 | Str 只测替换；PHP 缺陷产 indel → 会低估，需双标记/WGS |
| 跨物种/跨属 | 低 | 靶标热点、rrn 拷贝数、背景都变；只当数量级参考 |
| 涉及 rRNA 多拷贝 / 酶灭活 / 外排 | **不可用** | 单靶标 L-D 不成立；必须实测或换标记 |

**为什么只有"量级"**：`T_eff` 本身很少被测准（热点、密码子简并、选择强度都影响）；突变谱因 mutator 而异；不同药物的背景/抗性机制不同。三个因素各差 2–5 倍，乘起来就是 10–100 倍的不确定性。

## 8. 把先验变成"可校准"的

1. **同批并行测两个标记**（如 Rif + Str）：直接得到 `T_eff_Str/T_eff_Rif`，比查文献可靠；
2. **WGS MA**：数全基因组突变 → 得 `M`，再反算任一标记的 `T_eff`；
3. **敏感性**：把 `T_eff_Y/T_eff_X` 在 0.1–10 之间扫一遍，看窗口/C 是否稳健；不稳健就先测。

## 9. agent 必须走的"外推检查清单"

用户一说"我用 X 测的，想用到 Y"，**先走这 4 问，再给结论**；不得跳过直接把 μ_X 填成 μ_supply。

1. **源标记 X**：靶标是蛋白还是 rRNA？几拷贝？抗性机制是点突变、外排还是灭活酶？
2. **目标标记 Y**：同上三问。
3. **可比性**：同物种？同选择浓度？同一批培养条件？
4. **突变谱**：这个 mutator 有没有已知的 indel/替换偏好？

### 结论只有三种，必须明确说

| 结论 | 条件 | 下一步 |
|---|---|---|
| **可以给先验** | X、Y 都是单拷贝蛋白 + 点突变，同种同浓度 | `μ_Y ≈ μ_X × T_eff_Y/T_eff_X`，标 `assumed`；只用于定 C/窗口方向；再给 12 管试点 |
| **只能当量级参考** | 有一方机制不干净（如 X 是四环素/外排）或跨物种 | 不换算；先测 Y（或并行测两个标记） |
| **不可外推** | Y 是 rRNA 多拷贝 / 酶灭活 / 外排 | 必须实测；或换单拷贝蛋白标记 |

### 输出模板（agent 直接照这个说）

```
外推判断：<可以给先验 / 只能当量级参考 / 不可外推>
依据：源 <X> 是 <靶标/机制>；目标 <Y> 是 <靶标/机制>；<同种/同浓度?>
若给先验：μ_Y ≈ μ_X × (T_eff_Y/T_eff_X) = <值>（assumed，T_eff 比 = <比值>）
下一步：12 管试点测 <Y>（MIC/背景 + rate），回填后再 optimize；
       若窗口对 μ_supply 敏感，先测 Y，不要用先验硬跑。
```
