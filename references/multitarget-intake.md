# 多靶点：怎么问用户（agent intake）

> 目标：**用户不用懂任何参数**。agent 用 1–3 个问题问齐，自己跑、自己转述。
> 多靶点只有一条计算路径：`multitarget --f-step … --markers … --k … --nt … --genome-mb …`。

---

## 0. 三条原则

1. **永远不要让用户背参数名**——问什么、怎么问，是你判断的（见 §2）。
2. **"不知道"是合法答案，但必须先问**：缺参时**不得自行编造**，
   要把 CLI 打出的"缺什么 / 怎么拿到"原样呈现，等用户明确同意。
3. **先查菌株卡**：`Nt`、`G`、标定速率通常卡里都有；能自动取的不要问。

---

## 1. 路由：多靶点只有一条计算路径

| 用户说的话 | 走法 |
|---|---|
| "这个药，窗口怎么定 / 要多少细胞 / 乘客多少" | **直接进 window**（缺什么按 §2 问） |
| "帮我设计耐药实验" | 同上——f_step 路线本身就是"每步脉冲 + 配对铺板"的设计 |
| "我这突变株快 N 倍，对这药有没有用" | 先 §2 问齐 → window；F 只用于 QC 与代价判断 |
| "我什么都不懂，从哪开始" | **先给 `docs/start-here.md` 的三问** |

> 已移除（2026-11-13）：`--mode design/fit/classify`（用 μ 外推供给的旧路线）。
> 用户问"加速是线性还是超线性"——那是研究问题，不在本技能内；不要复活它。

---

## 2. 必问：三样，都得是实测/实配

| # | 问用户/怎么拿 | 字段 | 说明 |
|---|---|---|---|
| 1 | **f_step 测了吗？**（脉冲后在下一档浓度铺板：克隆数/CFU） | `--f-step` | 供给主参数，**不能用 μ 折算**；没测 → 给配对铺板方案（f₀/f₁ 各一块板，检出 1e-9 需 ~3×10⁹ CFU） |
| 2 | **标定标记测了几个？**（≥1 个单拷贝蛋白靶标的波动实验；推荐 2 个不同染色体域） | `--markers`（CSV：marker,mu,teff_bp[,f]） | μ 来自 `rate`；T_eff 文献值要标来源；两个标记差 >2× 先停下查机制 |
| 3 | **每步想要几个独立克隆？基因组多大？饱和密度多少？** | `--k` / `--genome-mb` / `--nt` | k 想拿几个写几个；G/Nt 读菌株卡 |

> F（mutator/WT）不在窗口计算里——它只回答"mutator 是否在工作"和"22×/139× 代价"。

---

## 3. 缺参时：不许自己编（硬流程）

```
1) 原样运行 → CLI 打印缺参清单 + 怎么拿到
2) 把那段原样贴给用户
3) 等明确答复：给了真值 → 带上重跑；"不知道" → 走 §2 的「怎么拿」
```

**绝对不能做**：自己编一个 f_step/μ 先跑、再在结果里标 assumed。
f_step 编不出来——它是**这次实验**的实测值。

---

## 4. 输出怎么转述（结论先行）

| 情况 | 转述 |
|---|---|
| 可行 | "这一步 N₀=…、脉冲 … 代就能拿到 k 个克隆；每克隆乘客 ≈ …，BGC 风险 …%" |
| 供给不足 | "f_step=… 时给不出 k 个克隆：加大 Nt/涂板量，或接受更少克隆" |
| spread>2 | "你的两个标记给出的每碱基率差 … 倍——先查 T_eff/机制，乘客先按区间报" |
| BGC 超限 | "乘客会把 BGC 打中 …%——缩短脉冲 / 降 k / 分更多步" |

**禁止说法**：
- "多靶点就是 78 的 k 次方"；
- "根据文献这个药是 S 类"（没有自己的证据不定类）；
- 把"标记位点平均 μ_perbp"说成"你的基因组的真实速率"（λ 未测，2–10× 误差棒；M 是 indel 意义上的下限）。

---

## 5. 与其它入口的衔接

| 用户已有 | 先跑 | 再跑 |
|---|---|---|
| 标记计数表 `r, Nt` | `rate` | `multitarget --f-step …` |
| WT/mutator 两批 | `compare`（F，仅 QC/代价） | `multitarget --f-step …` |
| 耐药克隆的 WGS | — | 数乘客 → 校准 M（`docs/mu-genome-derivation.md`） |

---

## 6. 一句话

**人是来问"行不行"的，不是来填参数的。**
你负责：认出这是多靶点窗口问题 → 问齐三样实测值 → 缺参等同意 → 结论先行地转述。
