# 多靶点：怎么问用户（agent intake）

> 目标：**用户不用懂任何参数**。agent 用 1–3 个问题问齐，自己跑、自己转述。
> 多靶点只有一条计算路径：`multitarget --records … --markers … --k … --capacity … --c-target …`（账本解释器：records 是唯一状态文件）。
> 但**先用 §-1 的 j 三问决定实验形状**——j=1 时不需要本命令，`optimize` 单窗直达。


## -1. j 三问（先于一切参数问题）

参数问齐之前，先让用户回答"**你要跨几档**"——这决定实验形状：

| 问 | 不知道时 |
|---|---|
| ① 你想把有效浓度**提高几倍**？（目标浓度 ÷ 现在能压住的浓度） | 必答 |
| ② 这类药「升一档」一般能提高几倍？（查同源药文献；脂肽常见 20–30 倍） | 查不到 → **第一档就当预实验**，测出来再算 |
| ③ 要跨几档：j = ⌈log(①)/log(②)⌉ | j=1 → 一个窗口搞定（`optimize`，走 `references/intake.md`）；j≥2 → 逐档账本（本命令） |

j≥2 时每档结束重算 j（mutator 会改道：pbio.3001878——可及路径集合可能变）。

### -0.5 首档三问（**没有账本时先问这个，别直接要 `--records`**）

| # | 问 | 没有时的下一步 |
|---|---|---|
| 1 | 你的菌对现在这个药，**最低抑菌浓度（MIC）**测过吗？ | 先测（肉汤稀释，半天）——它决定从哪个浓度起步 |
| 2 | **不加诱导剂**时，做过一轮浓度梯度铺板吗（1/2、1、2、4、8、16× MIC，每点 ≥3×10⁸ CFU）？ | 先做——它同时给出「假抗性」背景，缺了就扣不了背景、判不了红灯 |
| 3 | 第一档打算铺**几个不同浓度**的板？ | 少于 2 个 → 后面算不出药效的下降斜率；至少首档浓度上下各 1 个 |

三条都齐了，再按 §2 问 f_step / markers / k。完整剧本：`docs/protocol-execution.md` §1.5。

---

## 0. 三条原则

1. **永远不要让用户背参数名**——问什么、怎么问，是你判断的（见 §2）。
2. **"不知道"是合法答案，但必须先问**：缺参时**不得自行编造**，
   要把 CLI 打出的"缺什么 / 怎么拿到"原样呈现，等用户明确同意。
3. **先查菌株卡**：`Nt`、`G`、标定速率通常卡里都有；能自动取的不要问。

## 1. 路由：多靶点只有一条计算路径

| 用户说的话 | 走法 |
|---|---|
| "这个药，窗口怎么定 / 要多少细胞 / 乘客多少" | **直接进 window**（缺什么按 §2 问） |
| "帮我设计耐药实验" | 同上——f_step 路线本身就是"每步脉冲 + 配对铺板"的设计 |
| "我这突变株快 N 倍，对这药有没有用" | 先 §2 问齐 → window；F 只用于 QC 与代价判断 |
| "我什么都不懂，从哪开始" | **先给 `docs/start-here.md` 的三问** |

> 已移除（2026-11-13）：`--mode design/fit/classify`（用 μ 外推供给的旧路线）。
> 用户问"加速是线性还是超线性"——那是研究问题，不在本技能内；不要复活它。

## 2. 必问：三样，都得是实测/实配

| # | 问用户/怎么拿 | 字段 | 说明 |
|---|---|---|---|
| 1 | 你在**下一档浓度**上铺过板、数过克隆吗？（克隆数 ÷ 涂板 CFU，就是供给） | `--records` 行 | 供给主参数，**不能用 μ 折算**；没测 → 给配对铺板方案（f₀/f₁ 各一块板，检出 1e-9 需 ~3×10⁹ CFU） |
| 2 | 用**单靶点药**做过几组波动实验？（用来把速率换算成「每个碱基」，≥1 组，推荐 2 组不同染色体区域） | `--markers`（CSV：marker,mu,teff_bp[,f]） | μ 来自 `rate`；T_eff 文献值要标来源；两个标记差 >2× 先停下查机制 |
| 3 | 这一轮想要几个**独立克隆**？ | `--k` / `--genome-mb` / `--nt` | k 想拿几个写几个；基因组大小与饱和密度先查菌株卡，卡里没有才问 |

> F（mutator/WT）不在窗口计算里——它只回答"mutator 是否在工作"和"22×/139× 代价"。

---

## 3. 缺参时：不许自己编（硬流程）

```
1) 原样运行 → CLI 打印缺参清单 + 怎么拿到
2) 把那段原样贴给用户
3) 等明确答复：给了真值 → 带上重跑；"不知道" → 走 §2 的「怎么拿」
```

**绝对不能做**：自己编一个 f_step/μ 先跑、再在结果里标 assumed。
f_step 编不出来——它是**这次实验**的实测值。

---

## 4. 输出怎么转述（结论先行）

| 情况 | 转述 |
|---|---|
| 可行 | "这一步 N₀=…、脉冲 … 代就能拿到 k 个克隆；每克隆乘客 ≈ …，BGC 风险 …%" |
| 供给不足 | "f_step=… 时给不出 k 个克隆：加大 Nt/涂板量，或接受更少克隆" |
| spread>2 | "你的两个标记给出的每碱基率差 … 倍——先查 T_eff/机制，乘客先按区间报" |
| BGC 超限 | "乘客会把 BGC 打中 …%——缩短脉冲 / 降 k / 分更多步" |

**禁止说法**：
- "多靶点就是 78 的 k 次方"；
- "根据文献这个药是 S 类"（没有自己的证据不定类）；
- 把"标记位点平均 μ_perbp"说成"你的基因组的真实速率"（λ 未测，2–10× 误差棒；M 是 indel 意义上的下限）。

## 5. 与其它入口的衔接

| 用户已有 | 先跑 | 再跑 |
|---|---|---|
| 标记计数表 `r, Nt` | `rate` | `multitarget --records …` |

| 耐药克隆的 WGS | — | 数乘客 → 校准 M（`docs/knowledge-base.md`） |

## 6. 一句话

**人是来问"行不行"的，不是来填参数的。**
你负责：认出这是多靶点窗口问题 → 问齐三样实测值 → 缺参等同意 → 结论先行地转述。
