# PAP 尾部曲线：是什么、怎么测、不测行不行？

> 场景：用户问"PAP 是什么 / 有文献依据吗 / 板还没出结果就要转接，预测从哪来 / 不涂板直接液接液行不行"。
> 这五问是多靶点渐升（`multitarget --records`）最高频的概念疑问，本文给**可直接转述**的完整答案。
> 术语标注：[文献] = 有出处；[推导] = 算术可复算；[约定] = 本技能操作口径。
> 细节出处：`docs/protocol-ramp.md`（数学与边界）· `docs/protocol-fstep.md`（铺板规程）· `docs/protocol-execution.md`（时序与拓扑）。

## Q1 PAP 尾部曲线是什么？

PAP = **population analysis profile（群体分析谱）**：把一大群细胞铺在浓度梯度上数克隆，画出"多少细胞能扛多少浓度"的曲线（通俗版：**全班的考试成绩分布，不是一个平均分**）。

- 一块浓度 c 板上的克隆频率 f(c) ≈ **P(单细胞 MIC ≥ c)**——PAP 曲线就是群体 MIC 分布的**上尾实测** [推导]；
- 多数细胞敏感、少数亚群耐受时，分布在高浓度端**拖尾**——这是异质性耐药/持续细胞的表型信号 [文献：检出异质性耐药的标准做法]；
- **尾部** = 半对数坐标下近似直线的那段：

  ```
  log₁₀ f = a + s·c   ⟺   f(c) = f_ref × 10^(−(c−c_ref)/δ)，δ = −1/s
  ```

  δ（十倍频浓度宽）= **频率每掉一个数量级，浓度能抬多少**。它是规划器解可行步长的唯一"天气参数"。

## Q2 怎么测？

三个时机（主渠道**零额外实验成本**）：

| 时机 | 做法 | 出处 |
|---|---|---|
| **开跑前**（母株，无 mutator） | 先测 MIC；再铺 3–5 点浓度梯度（如 1/2/4/8/16× MIC），每点 ≥3×10⁸ CFU。半天工作量。同时抓：异质性耐药预警（f_pre 缓降不归零 → 先挑 10 个单克隆复测 MIC，别硬开跑）+ 背景频率 | `protocol-fstep.md` §1.1 |
| **每档顺带**（主渠道） | 每档脉冲结束，在工作浓度的 2×、4×（或 0.5×）**多铺 1–2 块板——其中一块本来就是下一步的工作板**。"一块板两用"：step_N 的 f_post 同时是 step_N+1 的 f_pre，账本是一串连续板 | `protocol-ramp.md` §0 · `protocol-fstep.md` §1.2 |
| **点不够时** | 见 Q4 的 S2 诊断 | `ramp.py` 阶段诊断 |

配套量化规则（`protocol-fstep.md` §2）：

- **板量倒推**：想以 ~95% 概率看到克隆，N_plated ≥ 3/f（rule of three，Hanley & Lippman-Hand 1983 [文献]）。f = 10⁻⁸ → 3×10⁸ CFU ≈ 3 块板；10⁻¹⁰ → 300 块 = 红线，先浓缩/加大体积再谈；
- **拟合规则**：同浓度多板自动合并；饱和点（f ≥ 0.5，`--sat-f` 可调）不进拟合；零克隆行不进拟合、按 rule of three 记检测上界 3/n（拟合值高于上界报警）；**≥3 个有克隆的浓度点**才给 δ 的 95% CI，否则只有点值并明注；
- **读板纪律**：统一"最早可辨"时刻、记录克隆出现时间与形态——板内新生突变和慢长克隆会污染高浓度端计数（`protocol-fstep.md` §5 坑 8/10）。

## Q3 有文献依据吗？

**钉死的（有 DOI/本地全文）**：

- PAP 方法本身是检出异质性耐药/持续细胞的标准做法 [文献]；
- **为什么供给必须实测、不能用 μ 折算**：`10.1371/journal.pcbi.1014666` 实测同一标记在波动实验与实际选择条件下 μ 差 **2–7×**——f_step/PAP 必须在实际选择条件下测，这是实测主义的文献实锤；
- 平稳补充假设的模型原型：`10.1371/journal.pgen.1011627` 的加性 log-MIC 模型 + 梯度孔自适应爬升的实测轨迹。

**钉得松的（要向用户坦白）**："PAP 尾部 log-线性"这一具体经验形态，技能内只标注"异质性耐药标准方法"，**未钉到具体 DOI**。若用户要写论文，建议补一篇原始文献（可用 paper-search 核实后钉上）。

## Q4 板要好几天才出结果，就要转接了——PAP 怎么"预测"下一档？

关键：**预测不在"转接当天"这个时刻发生**。技能把"预测"和"转接决策"拆成两件事，板结果滞后一档是设计内的（`protocol-fstep.md` §1.2）：

1. **转接当天不读板，也不需要读**。升档判据 = **预设阶梯 + 培养物"长回来了"**（浊度/CFU 增长恢复）——文献主流同款（morbidostat 按 OD 恢复自动升档，`10.1038/ng.1034`）。浓度阶梯是事先定好的，不是当天看数据挑。
2. **PAP 的预测发生在三个时刻**：
   - **开跑前（设计期）**：基线微型 PAP → δ → 可行最大步长 → 整条梯级形状（几档、每档 Δ、需铺 CFU、乘客账）。第一次预测用的是**母株基线**，不是上一档的板；
   - **每档板读数出来时（审计期，滞后一档）**：快生菌时间线"step_N 当天涂板+转接 step_N+1；次日读板，结果赶上 step_N+2 判读"。读数与上一轮预测并列对照——偏出 95% CI → 曲线重拟合、**剩余梯级**重算。渐升本就有 j≥2 档，滞后一档的审计仍覆盖后面所有档；
   - **红灯触发时（回滚期）**：背景淹没或连续两步无进展 → 从 step_N 甘油恢复、插半档重跑；下一档灭绝 → 甘油归档回滚（灭绝是常态：ncomms13002 的 16 条线系 7 条灭绝 [文献]）。
3. **为什么滞后一档可接受**：预测错的最坏后果是"下一档灭绝"，不是"结论错"——每步末甘油归档必做，任何一步可回滚，只损失时间不损失路线。反之串行等板：快生菌每步多等 1 天，**放线菌每步多等 5–7 天**，9 步渐升多耗一个多月。
4. **唯一真等板的**：阶梯最后一步的收尾确认（MIC 复核 + 生长速率）——终点没有"下一档"消化滞后，此时等板无代价。

**未测时技能会不会提示？会，四层**（缺了就停下给方案）：

- 缺 `--records` → 打印 S0/S1 阶段清单（S0：MIC + 基线梯度 3–5 点每点 ≥3×10⁸ CFU；S1：c₁、首窗、首档铺板 7 块板），并要求 agent 原样转达（`cli.py` 阶段诊断）;
- 有克隆的浓度点只有 1 个 → S2 诊断："回上一档洗后悬液，在 2× 与 4× 各补 1 个浓度点、每点 1–2 块板——三块板同时是下一档工作板，不是额外浪费"；
- 正克隆点 <3（δ 无 CI）→ 输出②显式提示"下档多涂浓度板补点"；
- f_pre 随浓度不下降（异质性耐药信号）→ 护栏 G23：先挑 10 个单克隆分别测 MIC，硬开跑结论作废。

## Q5 不做 PAP、直接持续液接液，行不行？

先拆开：**"液接液"和"不做梯度涂板"是两个独立决定**。液接液是本技能 2026-11-15 起的**默认推荐拓扑**（文献主流：Nat Commun 2026 `10.1038/s41467-026-74044-6` 1:50 串代 28 天爬到 ~1000×MIC，全程液体）——照用。但不做梯度涂板省的是每档几块板，扔掉的是整个预测层：

| # | 损失 | 后果 |
|---|---|---|
| ① | **没有 δ** | 无可行最大步长 → 退回"长起来就升"。反误区表原话：档距决定板量（3/N 检测限）与灭绝风险（`guardrails.md`）——档距大 → f_step 沿尾部指数下落 → 供给不足灭绝回滚；档距小 → 白多爬几档、乘客白多记 |
| ② | **没有 f_step → N₀/乘客优化失效** | `N₀ ≤ Nt_sat − k/f_step` 全成猜。高密度接种是最强降荷旋钮，f 估错一档 → 窗口代数偏长 → 乘客按 M_on 翻倍记。"尽量减少乘客"的目标直接放弃 |
| ③ | **四盏红灯全灭** | 背景淹没（f_pre ≥ 0.5×f_post）、f_post≈0（本档无供给）、f_pre 恒非零（持续细胞/污染）、饱和点漂移——全靠表型滞后才显现，发现时已多烧 1–3 档 |
| ④ | **检测限设计没了** | 3/f 规则告诉你下一档铺多少 CFU 才看得到克隆。不涂板连"这一档真没供给"和"板量不够"都分不清（零事件只说明 f < 3/N，N 不够大时上界无用） |
| ⑤ | **数据资产归零** | 终点只剩"最终 MIC × 几倍"+ WGS。频率轨迹、δ 演化、平稳假设审计全不存在，论文无法复述过程。pcbi.1014666 的逻辑：**预测器不审计 = 没有预测** |

**成本这边**："一块板两用"下每档边际成本只有 2–4 块板 + 一次稀释系列；板孵育与下一步生长并行，不占人力。**省几块板，扔掉 δ、N₀、四段账、四盏红灯。**

**如果板量实在受限，三档配置**：

| 配置 | 每档板量 | 保住什么 |
|---|---|---|
| 标准（文档默认） | 2–3 个浓度点 × 1–2 块 + 非选择板 | δ、审计、N₀ |
| 最低配 | 下一档浓度 1 块 post（+ 脉冲前同点 1 块 pre） | f_step 轨迹、背景扣除、N₀；δ 靠跨档累积，前期步长保守 |
| 零涂板 | 0 | 无预测、无审计、无乘客优化；预设小步长（1.5–2×）+ 甘油归档硬扛灭绝风险 |

**底线（转述时必说）**：pre 板（背景扣除的分母）和步末甘油归档（回滚保险）在任何配置下都不能省。
